# 11 · Ролик-свиток (сквозной проход): человек идёт слева направо сквозь череду знаменитых картин

Подход, использованный в ролике «Хуашу проходит сквозь знаменитые картины» (2026-10-05, 123,7 секунды, 24 мира). В отличие от спидрана по истории искусства (одна и та же комната меняет стиль изображения), здесь — **одна горизонтальная длинная лента-свиток**: каждый мир — горизонтально протяжённый фрагмент картины, соединённый встык со следующим; главный герой всё время идёт вправо, и в момент пересечения границы его стиль изображения меняется вместе с миром.

Демо: `scripts/engine/demos/long_scroll/`, включает 3 сегмента (египетская фреска → «Японский мостик» Моне → 8-bit пиксель-арт), около 15,6 секунды.

```sh
uv run --with playwright python scripts/engine/render.py --film demos/long_scroll --stills 1,5,9 --out 试渲   # три статичных кадра
uv run --with playwright python scripts/engine/render.py --film demos/long_scroll --out long_scroll.mp4       # весь фрагмент
```

Превью в браузере: поднимите статический сервер в `scripts/engine/` и откройте `index.html?film=demos/long_scroll`; `&only=28_monet,14_8bit` — выстроить только эти сегменты, `&v=330` — попробовать другую скорость шага.

## Файлы

| Файл | За что отвечает |
|---|---|
| `eras.js` | Точка входа ролика: загрузка библиотек, `FILM_ORDER` (порядок сегментов), регистрация библиотек кадров, создание одного сегмента с `dur = WORLD.total` |
| `lib/world.js` | Каркас `WORLD`: временная шкала (идёт → останавливается для взаимодействия → идёт), движение героя, камера, герой, разрезанный по границе, границы, угловые подписи. **Сначала прочитайте комментарий в его начале** |
| `lib/crossing.js` | `XING`: чтение библиотек кадров, отрисовка кадров персонажа (`XING.actor`), материал мазков, мир Моне |
| `lib/acts.js` | `ACT`: инструменты для маленьких сценок (траектория камешка, «блинчики» по воде и т. п.) |
| `lib/xing2_*.js` | Небольшие утилиты, общие для нескольких сегментов; подгружаются по необходимости в начале файла сегмента |
| `segments/<id>.js` | Один мир — один файл, вызывает `WORLD.add({...})` |
| `frames/<key>/` | Библиотека кадров персонажа: 8 прозрачных PNG + `meta.json` (для каждого кадра — точка привязки подошвы `ax/ay`, размер, отрыв от земли `air`; `ref_h` — рост стоящего героя в пикселях) |

## Добавить сегмент

1. Создайте в `segments/` файл `<id>.js`, вызывающий `WORLD.add({ id, year, name, w, hero, acts, back, front, seam })`; интерфейс описан в комментарии в начале `lib/world.js`. Сам мир рисуется кодом; предпочтительно переделать уже готовую стилевую сцену из `scenes/<id>.js` в горизонтально протяжённую версию (ширина сегмента 2000–2800).
2. Сгенерируйте кадры персонажа: для каждого мира — лист «ходьба, 8 кадров», при наличии взаимодействия — ещё лист «взаимодействие, 8 кадров»; модель генерации перерисовывает их в стиле изображения мира, зелёный фон, нарезка кадров (`scripts/key_split.py`, способ — в № 10), положите в `frames/<key>/`, заполните `meta.json`.
3. Добавьте `<id>` в `FILM_ORDER` в `eras.js`.
4. Отрендерите статичные кадры, проверьте обе стороны границы, затем запустите `qa.py --project scripts/engine --film demos/long_scroll` — детерминизм обязан быть ✓.

## Ключевые соглашения (едины для всего ролика, зашиты в каркас)

- **Линия земли `WORLD.GROUND = 760`, рост стоящего героя 300, герой находится на 720px кадра.** На обоих концах сегмента (около x=0 и x=w, ±150px) земля обязана возвращаться к 760, горизонт желательно держать в пределах 480–560 — только тогда обе стороны сойдутся при пересечении границы. В середине могут быть мосты, ступени (`ground: lx => y`).
- **Все события отсчитываются от «начала взаимодействия».** Через `WORLD.actT(сегмент)` получите момент начала взаимодействия во времени всего ролика, `r = S.t - WORLD.actT(ME)`; не пишите «на такой-то секунде после входа в сегмент». Скорость шага всего ролика позже подняли с 330 до 560, и в сегментах, написанных по этому правилу, не пришлось менять ни строчки.
- **Камера только вперёд, никогда назад.** Цель камеры = x героя − 720 + `lead`, на который она уступает вперёд во время взаимодействия; берётся исторический максимум и сглаживается гауссом, поэтому движение всюду монотонно, без рывков при остановке и старте. Если во время взаимодействия камера не должна двигаться — пишите `lead: 0`.
- **Граница каждого сегмента рисуется фирменным языком этого сегмента** (`seam`: край бумаги, пиксельная шахматка, разделительные линии цветовых блоков…) — это версия правила спидрана «переход = фирменный язык следующего стиля» для свитка.
- **Частота кадров ходьбы героя пропорциональна скорости шага** (`hero.fps`), 8 кадров на цикл походки; если нужно пропустить героя ещё через слой материала стиля, напишите в сегменте `hero.draw(c, key, i, o, S)` и компонуйте сами, не меняя общую библиотеку.
- **Музыка**: сначала утверждается картинка, потом подбирается музыка. В каждом сегменте целое число долей, темп посегментно подстраивается в пределах 86–104 BPM, чтобы каждая граница приходилась на первую долю такта (по замеру максимальная ошибка на 24 границах — 11,7 мс); посегментную разницу темпа в ±8% ухо не слышит.
- **Не добавляйте герою шуток, о которых не просили.** В каркасе есть функция «стопка сувениров на шляпе» (`FILM_HAT_ITEMS`), она легко перетягивает внимание со сцены и по умолчанию выключена.
