# 10_nouveau · 1896, ар-нуво (плакаты Мухи)

Файл: `scenes/10_nouveau.js` (около 300 строк). Производительность: warm в среднем 29ms, максимум 37ms, первый кадр (построение кэша) ≈80ms; детерминированность пройдена (при одном и том же lt два прогона попиксельно идентичны); разница движения lt 0.35→0.65 — 13.1% пикселей. В ролике держится 0.70s (органический волновой переход T09 длится 0.24s и вырастает из (1330,320) = нимба девушки).

## Конвейер
1. **Подложка полностью в кэше `nv_bg`**: трёхступенчатый вертикальный градиент серо-зелёный → бежево-зелёный → персиковый (`#b9cba0`→`#cfd3a6`→`#ecc9a2`, только во внутренней рамке 34..1886×32..907); узор из кружков = кольцо r10 + точка в центре r2.6, шаг рядов 54, столбцов 62, нечётные ряды сдвинуты на 31 (ромбическое шахматное чередование), цвет `rgba(120,140,100,.38)`; маленькая fbm-картинка 240×135, увеличенная и наложенная с α0.5, даёт литографическую пятнистость (в сотни раз быстрее, чем считать шум на весь экран); полоса мозаичной плитки — клетка 20×24, 9 цветов по циклу `(k*7+(k>>2))%9` вразброс; зелёный баннер `#8fac80`; заголовок `Marcellus-400` 76px, letterSpacing 12, сначала тёмно-коричневая обводка 7px, потом заливка кремово-белым; золотая рамка = внешнее золото 6px `#c9a24a` + две тёмно-коричневые линии 2px снаружи и внутри.
2. **Путь переменной толщины `ribbon(pts, w(q))`**: последовательность точек сначала уплотняется Catmull-Rom (4–10 точек на сегмент), каждая точка смещается по нормали на w/2 в обе стороны, получается замкнутый многоугольник для fill. Все «удары хлыста» сделаны им: стебли, листья, кованые ножки стола, растительный завиток баннера, волосы, пар. `swellW(wmax)` = заострено на обоих концах, толще в середине (огибающая sin) — это и есть «дыхание» толщины линий Мухи. Спиральное завершение `spiral(cx,cy,r0,a0,turns,dir)`: радиус линейно сжимается до 15%.
3. **«Толстый внешний контур, тонкие внутренние линии» в духе Мухи — приём смещения общего силуэта**: персонажи (кот + девушка + волосы + шаль) целиком рисуются во внеэкранный слой L (режим both из RIG, lw 2 → внутренние линии правильно перекрываются в порядке деталей); затем копия L через `source-in` окрашивается в тёмно-коричневый `#4e3320` и на основном холсте подкладывается под L с тремя смещениями (-1.5,-1.5), (3.5,4.5), (2,2.5). Результат: по внешнему краю силуэта кайма 1.5px, справа снизу толстый край 4–5px; внутренние линии остаются 2px. Всего 3 лишних полноэкранных drawImage.
4. Зерно `P.grain('nv', .05, тёплый коричневый, .14)` поверх всего, как в литографии.

## Анимация мотивов (всё должно быть видно в пределах 0.7s)
- **Восход солнца**: по замерам оригинала (кадр 509 (583,400) → кадр 530 (576,299), ≈-5px/кадр) записано как `sy = 400 - (lt-0.267)·288`, `sx = 583 - (lt-0.267)·20`, при lt=0 на 477 (спрятано за горой), при lt=0.7 доходит до 275. Цветные полосы холмов рисуются после солнца = естественное перекрытие «восходит из-за горы».
- **Вращение свинцовых лучей**: 14 радиальных свинцовых переплётов от центра солнца r92→r420, угол `+lt·0.9·0.25` медленно вращается с качанием ±0.04; переплёты движутся вместе с солнцем, поэтому меняется всё членение стёкол окна — это самое заметное движение в окне.
- **Полоса цветного стекла**: по внутреннему краю арки (прямые стороны + эллиптическая дуга rx219 ry130) каждые 17px ставится цветная пластинка 14×14, повёрнутая по касательной, цикл из 6 цветов.
- **Качание маков / лилий**: горизонтальное смещение головок цветов `sin(7.5t+φ)·13 + sin(3.1t+2φ)·5`, стебель — кривая ribbon с тремя контрольными точками, двигается только верхний участок; левый и правый куст в противофазе; листья с амплитудой 0.3.
- **Вращение нимбов**: нимб девушки R172, 18 круглых заклёпок вращаются `+0.9t`, внутреннее кольцо из 32 лепестков розы-окна — обратно `-0.63t`; нимб кота R106 — восьмилепестковый оранжевый цветок `-1.1t` + золотое пунктирное кольцо, движущееся через lineDashOffset.
- **Волосы**: сначала большая масса волос (smooth по 16 точкам, внешний край колеблется по `sin(6t+y·0.035)·9`), затем 7 локонов за спиной + 2 локона перед плечом: каждый — S-кривая из 12 точек `sin(7.4q+φ-7t)·(6+20q)` (бегущая волна вниз), на конце спираль в 1.2 оборота, ширина убывает 14–18 → 2.5, кремово-жёлтая светлая сердцевина + тонкая тёмно-золотая линия. 6 маленьких завитков по внешнему краю макушки дают объём. Все точки следуют за смещением `G.A.headC` (двигаются вместе при запрокидывании головы на глотке, чем ниже, тем меньше).
- **S-образный декоративный пар**: 3 кремово-белые ribbon (ширина 26/20/14) + коричневая обводка 1.8px + средняя линия, бегущая волна `sin(4q+φ-6t)·(18+70q)`, горизонтальный интервал расходится с высотой ×(1+2.6q), на конце спираль 34px; всё целиком наклонено влево `lean = -90 - 160·cup` — **грабли**: choreo поднимает чашку к губам, и если пар поднимается вертикально, он пересекает лицо девушки, поэтому он обязан наклоняться в сторону окна вместе с cup.
- choreo: подъём чашки, запрокидывание головы, моргание, взмахи хвоста, дыхание — всё из RIG; блюдце остаётся на столе (после того как чашку унесли, столешница не пустая).

## Грабли
- **`drawGirl(mode:'line')`, наложенный самым верхним слоем, прорисовывает контуры скрытых деталей (дальний рукав) сквозь торс** (в эталоне 09 то же самое). Изменено: во внеэкранном слое линии рисуются в режиме both в порядке деталей, затем целиком делается толстый внешний контур.
- Волосы сначала были 7 длинными лентами шириной 34px — как сосиски / лапша; волосы Мухи = масса волос как основа + тонкие S-образные локоны + спиральные окончания, ширина ≤18.
- Для разницы в самопроверке не брать кадры с lt<0.33: в первые 20 кадров после начала перехода у движка есть масштабирование «удара на бите» 1.03, и разница краснеет на весь экран.
