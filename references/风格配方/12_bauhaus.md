# 12_bauhaus · 1923 плакат Баухауса

Файл: `scenes/12_bauhaus.js` (около 210 строк). Производительность: warm в среднем 5 мс, максимум 9.5 мс, первый кадр ≈85 мс; детерминизм пройден; разностный анализ движения lt 0.34→0.46 — 4.9% пикселей (движутся чёрный стержень, оконная решётка, концентрические дуги, кошка, мяч, фигура-марионетка). Длительность в ролике 0.47 с (переход T11 «синий квадрат / красный круг / жёлтый треугольник / круглое отверстие» 0.20 с, начало в (1330,590) ≈ центр красного круга).

## Пайплайн
1. **Фон полностью в кэше `bh_bg`**: кремовая старая бумага `#ebe3cf` + маленькое fbm-изображение 320×180, растянутое с α0.5 (состаренные пятна) + сквозная тонкая наклонная линия (40,170)→(1900,840) (под окном) + чёрная горизонтальная полоса слева вверху (60,61,256,13), красная вертикальная полоса (292,105,24,468) + вертикальная надпись bauhaus (`Poppins-800` 210px, после `rotate(-π/2)` масштабируется по горизонтали ровно до 820px длины, начало (262,1000), читается снизу вверх) + маленький серый квадрат + линия пола (345,898)-(1860,915) + жёлтый прямоугольный треугольник + katze (Poppins-800 150px, красный `#d3262b`) + две строки Poppins-600 31px справа внизу + стол с чёрной столешницей / хромированными трубчатыми ножками (трёхцветный линейный градиент) + консольный стул Брейера (один и тот же путь обводится 15px тёмно-серым / 10px хромом / 3px бликом со смещением 2px) + два слоя зерна (тёмные точки плотностью 0.02, α0.35 — чёрные пятна старой печати).
2. Красный круг кэшируется отдельно 520²: основной цвет + через `source-atop` светлые fbm-пятна α0.55 — имитация неровной краски шелкографии / литографии.
3. Персонажи и композиция целиком из геометрических фигур: никаких криволинейных обводок, только круги, квадраты, треугольники, толстые стержни.

## Мотивные движения
- **Длинный наклонный чёрный стержень поворачивается, как стрелка**: углы, покадрово измеренные по оригиналу (кадры 575–579 — 28°, 581 — 33°, 583 — 37°, 585 — 42°, 587 — 46°, 591 — 49.5°), записаны как `deg = 28 + 21.5·easeOut(clamp((lt-0.26)/0.22))`. Ось вращения = центр втулки (1125,195) (подтверждено сравнением кадров 576/590 оригинала: втулка неподвижна, нижний конец опускается), стержень 27px от -432 до +150, тонкая параллельная линия смещена на 30px, короткий красный стержень — на -30px, дуга внутри втулки вращается вместе с ним.
- **Смена клеток окна в духе Мондриана**: сетка 4×4 (внутренняя рамка 366..794 × 126..561, клетка 100×101, зазор 9.5), в смене участвуют 6 клеток, привязка к 13fps `step=floor(lt·13)`, у каждой клетки своя фаза, смена только при `(step+2·sw)%9 < 6` (не на каждый такт — ритм не механический); цвета для смены — только красный, жёлтый, синий, кремовый, светло-голубой, серый. Клетка с узором (клетчатая бумага 9px) и клетка с четвертью круга сохраняются.
- **Концентрические дуги**: 6 дуг справа от красного круга, фаза начала колеблется по `sin(9lt-0.7i)·0.05`, радиус «дышит» на `±3`, длина дуги за 0.4 с растягивается с 55% до 100% — как звуковая волна, расходящаяся наружу.
- **Пар над чашкой**: одна тонкая синусоида 2.2px (26 периодов / 170px, бегущая волна `-18t`), затухание линейным градиентом.
- **Кошка толкает мяч, и он катится**: правая передняя лапа `tap = sin(clamp((lt-0.05)/0.16)·π)` выдвигается на 36px и возвращается; синий мяч r31 на `lt 0.13→0.47` с easeOut катится от x712 до 816, **угол поворота = смещение / радиус** (по белому диаметру + белой точке видно, что он катится), во время качения позади две линии скорости. Хвост = толстая оранжевая дуга 26px + тёмно-оранжевые полосы-пунктир той же ширины, угол следует `choreo.tail·0.5`.

## Геометризация персонажей (все опорные точки из RIG)
- **Марионетка Шлеммера**: голова = круг r70 (`G.A.headC + (14,-18)`), золотые геометрические пряди = сектор задней половины головы (-1.95→1.15rad) + треугольник на лбу + круглый пучок r34 + полукруглая прядь сзади (`G.A.back`); лицо = чёрные вертикальные полоски-глаза (при моргании становятся горизонтальными), красные квадратные щёки, короткий чёрный рот. Вся группа головы вращается вокруг `G.A.neck` по `G.tilt` (запрокидывает голову при глотке). Торс = синяя трапеция + чёрная трапеция задней половины (поднимается и опускается по breathe); юбка = чёрный сектор r178 + синяя трапеция; конечности = толстые чёрные стержни со скруглёнными концами, суставы = кремовые диски + чёрное кольцо 5px + чёрная точка в центре. Ближняя рука напрямую использует `G.A.shoulder/elbow/hand` (IK из RIG держит чашку), дальняя рука лежит на столе (воспроизводит руку из оригинала, протянутую к столешнице).
- **Кошка**: тело — круг r100 (вычислен из `K.box` (536,805), масштабируется по breathe) + слева 4 тёмно-оранжевые горизонтальные полосы (clip внутри круга) + кремовый сектор справа внизу (оранжево-белые блоки); голова = квадрат 104 (`K.headC + (14,48)`, слегка поворачивается на ±0.08rad в фазе хвоста) + жёлтые треугольные уши + кремовая нижняя половина морды + тёмно-оранжевая полоса на лбу; глаза = белый круг + чёрный вертикальный зрачок-полоска.

## Грабли
- В первой версии клетки считались по 107px, справа вылезали за чёрную рамку на 16px — размер клеток окна нужно выводить из «ширина внутренней рамки − 3 зазора».
- В цвета для смены был включён чёрный: при смене на чёрную клетку всё окно резко тяжелело и выглядело как битая клетка — убран.
- Рот марионетки сначала был нарисован как в оригинале — длинной чёрной полосой, выходящей за голову; на лице девушки это выглядело как сигарета во рту, заменено на короткую черту внутри головы.
