# 05_gothic · 1290, готический иллюминированный манускрипт

11–22ms на кадр (медиана 12ms). Статичный слой + маска сусального золота строятся один раз в `init()`.

## Конвейер
1. Статичный слой `goth_static` (кэш): пергамент → сусальное золото → ромбическое тиснение → щипец, пинакли, боковые колонны → стрельчатое окно и витраж → стол, трон → колонка латинского текста → маленький рыцарь на полях.
2. Маска сусального золота `goth_mask`: по статичному слою попиксельно считается «золотистость» `clamp((r-b-70)/50)·clamp((g-b-30)/40)·clamp((r-140)/40)`, результат используется как alpha. У пергамента (236,223,194) r−b всего 42 — исключается; у розовых полос высокое b — тоже исключаются. **Не нужно ещё раз рисовать золотые формы для маски**: всё, что золотое, автоматически попадает под проход блика — фон, инициалы, золотые шары, навершия щипцов.
3. Каждый кадр по порядку: мерцание витража → косой блик → четырёхконечные звёзды там, где проходит блик → орнамент из лозы → улитка → пробегающая мышь → кот → девушка → зерно.

## Фактура сусального золота («мелкая текстура + блик» по спецификации)
- Попиксельное затенение: `f = 0.52 + fbm(x·.0035)·0.42 + горизонтальные следы шлифовки noise(x·.004, y·.09)·0.5 + свет слева сверху + зерно ±0.05`, затем интерполяция между тремя цветами goldLo #9c6a1a / gold #d9a63a / goldHi #f8de86. Частота следов шлифовки по y более чем в 20 раз выше, чем по x, поэтому выглядит как горизонтальная металлическая шлифовка.
- Ромбы: шаг 46px, два семейства диагональных линий (x+y и x−y постоянны). Каждая линия рисуется дважды: один раз тёмная, один раз светлая со смещением 1.2px — выглядит как вырезанная в золоте. В центр ромба вдавлены 4 точки, слева сверху светлые, справа снизу тёмные.
- Каждые 118×125px рисуется очень бледный квадратный шов, имитирующий отдельные наклеенные листы золота.
- Косой блик: сначала на scratch шириной 920px рисуется полоса линейного градиента, наклон K=0.45 (направление «/»). Умножается на маску через `destination-in`, затем через `lighter` с α0.62 накладывается обратно на кадр. **Движется равномерно** `x = lerp(150,1650,(lt-0.08)/1.15)`. Сначала было inOut-сглаживание — в итоге к 0.9s блик уже уходил из золотой зоны и на девушке его не было видно; после перехода на равномерное движение блик доходит до окна к 0.3s и ровно к 0.9s проходит по девушке. Нимб и 11 фиксированных точек по условию `|u − sweepX| < 70` вспыхивают четырёхконечной звездой, когда проходит блик.

## Анимация мотивов (всё заметно в окне 0.25–1.4s)
- Лоза: у двух стеблей примерно по 120 точек, к каждой точке добавляется колебание `sin(t·2.1+i·.09)·2.5`. Через каждые 3–5 точек подвешивается трёхлопастный лист плюща (по очереди синий / красный / золотой) или золотой шар с 3 усиками. Листья качаются вокруг точки подвеса по `sin(t·3.1+k·1.7)·0.28`. В первой версии масштаб листьев был 0.85 — слишком мелко и редко; после изменения на 1.05–1.45 плотность приблизилась к оригиналу.
- Витраж: 26 случайных точек, при `sin(t·5+h·40) > 0.6` загорается пятно белого радиального света.
- Кот поднял одну переднюю лапу и держит мышь за хвост, мышь качается как маятник `0.32·sin(t·5.5)`, беспорядочно дрыгая лапками. Улитка ползёт влево со скоростью 62px/s, шевеля рожками; мышь под колонкой текста за 0.12–1.17s пробегает 360px, ноги качаются на 40 радиан в секунду.
- Девушка по общей хореографии поднимает золотую чашу, на краю чаши мерцает четырёхконечная звезда, пар над чашей — тонкие чернильные линии.

## Персонажи
- Девушка рисуется вручную по порядку прямо из Path2D `RIG.girl`, **без вызова `RIG.drawGirl`**, по двум причинам: drawGirl обязательно рисует кружку с ручкой; плащ и нимб нужно вставлять между определёнными слоями. Порядок отрисовки: нимб (центр в headC со смещением (16,−22), r=114, красный круг плюс 36 вдавленных точек) → волнистые длинные золотые волосы → красное одеяние (тонкие золотые вертикальные полосы через каждые 20px, по подолу золотая кайма) → синий плащ (закреплён на nape/back, с золотой каймой) → голова → золотая чаша.
- Кот сделан «котом с человеческим лицом» из манускриптов: лицо — кремовый эллипс, зрачки миндалевидных глаз сдвинуты вправо и косятся на девушку, верхние веки утолщены, брови подняты, уголки рта опущены, на щеках румянец. Используется только `legs[0]`, вторая передняя лапа нарисована вручную через `RIG.limb` в поднятой позе.
- Основной латинский текст — UnifrakturMaguntia 44px. При 50px «cum poculo suo» выталкивается за правый край кадра. Первые слова предложений Cattus/Nemo/Mus — киноварью, это средневековая практика рубрикации.

## Грабли
- scratchpad общий с авторами других эпох, `check.py` однажды был перезаписан кем-то другим. Скрипты самопроверки нужно класть в свой подкаталог.
- Если брать lt=0 как базу для карты разницы движения, она загрязняется ударом камеры движка в первые 20 кадров (масштаб 1.03). Базу нужно брать при lt≥0.35.

## Подстройка v2
Амплитуда лозы ×2, качание листьев 0.42; 40 точек мерцания витража; α блика на золоте 0.85, полоса блика шире. Покадровая разница на статичном отрезке 1.10 → 1.32 (оригинал 1.64).
