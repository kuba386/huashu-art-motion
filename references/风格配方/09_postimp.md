# 09_postimp · 1889, Ван Гог (эталонная реализация)

Файл: `scripts/engine/scenes/09_postimp.js`, около 110ms на кадр (три полнокадровых прохода мазков). Остальные эпохи пишутся по его структуре.

## Конвейер
Плоский черновой слой (большие плоскости стены / пола / окна / кровати) → перерисовка мазками по полю потока (зональные палитры) → слой реквизита (стол, стулья, ваза, рамы картин, люстра — отдельными мелкими мазками через source-atop) → линейный рисунок окружения (тёмно-синий 4.5px, «кипение» на 8fps) → персонажи (плоская заливка → тонкие мазки через source-atop → добор линий и черты лица) → подвижные блики (пунктирные кольца ореола лампы расходятся наружу, мерцают звёзды, пар).

## Ключевые параметры
- Поле направлений: стена вертикально −π/2 ± 0.22·noise; пол — вдоль линий перспективы к точке схода (960,330); звёздное небо — по касательной к ближайшему вихрю + вращение 0.3t; ореол лампы — по окружности; изголовье кровати вертикально, простыня почти горизонтально.
- Три прохода мазков: не стена и не пол — cell10 len22 w6.5; стена — cell14 len64 w8; пол — cell12 len46 w8. Обводка outline 0.8–0.9, примесь 40–45% тёмно-синего. Смена сида на 8fps.
- Зональные палитры (P.swatch, mixBase 0.3–0.45): стена `#7f9be6 #5f7fd8 #a7bbf2 #6c6fd2 #8ad0e6 #c3cbf6 #4f6cc8 #9a8fe0`; звёздное небо `#22339a #2f4fb8 #5c86dc #8fb6ee #1b2a78 #3c6bd0`; пол `#c0573c #a8453a #d7774a #8e3b30 #5f8f6a #c96a52 #e08a5c`.
- На теле кота 7 витков рыжей / светло-рыжей спирали (clip по телу, вращение 0.6rad/s) — «кот-вихрь» из оригинала.

## Грабли
- Один набор параметров на всё изображение превращает его в ковёр: стену, пол и остальное обязательно делать тремя проходами.
- Мелкие предметы разбиваются крупными мазками: всех их выносить в слой реквизита.
- Одно лишь дрожание цвета даёт «шум одного и того же синего», ощущение Ван Гога создают десяток с лишним оттенков в зональной палитре.
