# 26_vaporwave · 2011 Вейпорвейв / кибер-неон

> Источник: тест переноса B (выполнен независимым агентом, который только читал skill, 2026-10-04). После интеграции код сцены перенесён в `scripts/engine/scenes/26_vaporwave.js`.

Имя файла в эксперименте: `scenes/c5_vaporwave.js` (около 210 строк). Красный флаг на ревью: в первой версии кофта была розовой, сливалась с розоватым тоном кожи и читалась так, будто персонаж без одежды. Заменено на лавандово-фиолетовый плащ `#8f7cf6` + белый треугольный воротник + бирюзовая линия молнии. Медиана на кадр 49 мс; разница между кадрами 25% (VHS-постобработка заставляет двигаться весь экран).

**Пайплайн**: весь кадр сначала рисуется в офскрин S, затем VHS-постобработка выводит его в c (счётчик движок рисует в самом верхнем слое, хроматическая аберрация на него не действует).
1. Стена: тёмно-фиолетовый вертикальный градиент `#0d0322 → #4a0f6a` + пурпурный радиальный свет у окна и бирюзовый радиальный свет у вывески. Внизу стены — бирюзовая светодиодная полоса.
2. **`glowLine(c, col, w, blur)`**: один и тот же путь сначала обводится толстым свечением через shadowBlur, затем тонкой почти белой сердцевиной 2–3px — получается неоновая трубка.
3. Закат в окне: солнце — вертикальный градиент жёлтый → оранжевый → пурпурный, через `destination-out` в нём прорезаны 7 горизонтальных щелей, ширина щели растёт с глубиной (2 + q²·16), всё солнце поднимается со скоростью 0.9/s. Горизонт — каркасные горы (пурпурное свечение), под ними бирюзовая перспективная сетка катится к зрителю, по бокам качаются силуэты пальм.
4. Пол: пурпурная перспективная сетка, точка схода (960,600), горизонтальные линии `y = 600 + 520/d`, d = k + 1 − phase (phase = 1.3t mod 1), толщина линий растёт к переднему плану.
5. **Неоновая вывеска «カフェ» — трубки рисуются вручную ломаными** (без зависимости от шрифта): каждая кана — 1–3 штриха, в единичных координатах (u,v). Каждый символ мигает по хешу кадра: `hash(floor(30t), k) < 0.07` — гаснет; «フ» дополнительно гаснет с вероятностью 22% при `f mod 17 < 5`, в погашенном состоянии рисуется тёмно-фиолетовая трубка.
6. Диалоговое окно Win95 TEA.EXE: серый корпус, заголовок с тёмно-синим градиентом, блоки прогресса `3 + 14lt` делений, процент `18 + 70lt`. Мраморный бюст на столе (профильный силуэт из 22 точек, фиолетово-серый градиент + прожилки + розовый контровой свет + мем с солнечными очками).
7. Персонаж: розовый свитер, длинная бирюзовая плиссированная юбка, светлые волосы + розовая резинка. Светящийся контур «розовый со стороны окна, бирюзовый со спины»: один и тот же набор путей обводится дважды, с clip по левой и правой половине экрана соответственно.

**VHS-постобработка `vhs(c, S, t, lt)`**
- Разделение RGB: для каждого канала S рисуется во временный холст, `multiply` чистым цветом `#ff0000/#00ff00/#0000ff` выделяет один канал, затем каналы со сдвигом складываются через `lighter` на чёрном фоне. Величина сдвига 3 + 1.5sin(7t), эпизодически (hash<0.12) +6.
- Полоса трекинг-шума: высота 70px, ползёт вниз по `(520lt + 200) mod (H+160)`. Внутри полосы каждые 6px — горизонтальный сдвиг `±30·sin(πy/bh)`, сверху 90 бело-серых шумовых линий.
- Сканлайны: паттерн-тайл 4×4 (строка 0 α 0.28, строка 2 α 0.12). OSD: PressStart2P «PLAY» + нарисованный вручную ▶ (в шрифте нет такого глифа), мигает каждые 16 кадров; дата в левом нижнем углу и таймкод идут по lt.

**Палитра**: пурпурный `#ff4fd8`, ярко-розовый `#ff2f8f`, бирюзовый `#3ff6ff`, тёмно-фиолетовый `#12052a / #2a0b4a`, солнечно-жёлтый `#ffd84a`, оранжевый `#ff8a3a`.

**Подводные камни**
- Полноширинного «ＶＡＰＯＲＷＡＶＥ», ▶ и японского нет в `lib/fonts` — происходит тихий откат на системный шрифт. Подпись переведена на полуширинные символы + межбуквенный интервал 7, ▶ и кана рисуются вручную.
- Обводка персонажа идёт по путям отдельных частей, поэтому линия талии и стыки рук с торсом тоже светятся. Для неонового лайн-арта это допустимо, но если нужен чистый внешний контур, сначала нарисуйте силуэт в офскрин, а затем обведите края офскрина.
