# 22_constructivism · 1924 плакат русского конструктивизма (Родченко / Лисицкий)

> Источник: тест переноса B (выполнен независимым агентом, который только читал skill, 2026-10-04). Код сцены после объединения перенесён в `scripts/engine/scenes/22_constructivism.js`.

Имя файла во время эксперимента: `scenes/c1_constructivism.js` (около 175 строк). Медиана на кадр 5 мс; разница кадров 3.6%.

**Пайплайн**
1. Фон полностью в кэше `cs_bg`: кремовая старая бумага (`P.texture` `#e9dfc4`, dark `#d9c9a4`) → слева наклонная чёрная полоса (rotate −0.5), красный квадрат (rotate 0.26), 5 строк чёрных полос «основного текста» → справа тонкие наклонные линии, красная точка, в чёрной вертикальной полосе вертикальная геометрическая надпись «ЧАЙ» → большой чёрный круг за головой персонажа (центр (1330,395), r 215) → наклонный красный пол (0,905)→(1920,856), по верхнему краю чёрная линия 12px → окно → чёрный стол (красная кромка, косые распорки) → табурет-чёрный блок.
2. **Окно = фотоколлаж**: сначала в offscreen рисуется «фотография» в оттенках серого (градиент неба `#5e5e5e→#e8e8e8`, радиальные белые облака, тёмные силуэты заводских корпусов, трубы), затем растрируется через `halftone()` (cell 7, gain 0.8); Шуховская башня рисуется чёткими чёрными линиями поверх растра (пять секций-гиперболоидов, в каждой две группы по 18 прямых образующих, разность фаз ±1.1rad, задняя сторона с sin<−0.2 опускается) — это и есть коллаж «фотография + рисунок от руки».
3. **Кожа = растровая фотография**: лицо, шея, руки сначала рисуются в offscreen градиентом серого (спереди светлее, сзади темнее, `#fafafa→#9c9c9c`), затем растрируются (cell 4.6, gain 0.74, 45°). Под растром подложка кремового цвета, снаружи сначала обводка 7px `#fbf7ea` — эта кайма и есть белый край вырезанной фотографии. Черты лица дорисованы чётким чёрным пером, губы вручную подкрашены красным. Одежда — сплошь плоская заливка как вырезанная бумага + чёрная линия 3px; тени — `shadeDots()`, растровые точки внутри пути по функции.

**Ключевые функции**
- `halftone(c, src, bx,by,bw,bh, cell, col, gain, ang=π/4)`: выборка серого из src на повёрнутой сетке, диаметр точки = cell·gain·√(1−L), точки ставятся только там, где alpha>128. **Все точки объединяются в один path, fill — один раз**. На лице около 3000 точек, время <2 мс.
- Геометрическая кириллица: модули 5×7, каждая буква — несколько прямоугольников или многоугольников (диагональ Й — четырёхугольник, краткая — маленький прямоугольник сверху). **Каждая деталь — отдельный fill**.

**Мотивные движения**
- Красный клин Лисицкого вонзается в чёрный круг: вершина ходит туда-обратно вдоль оси 0.34rad, `70·(0.5−0.5cos(2π·1.6·lt))`.
- Красное пунктирное кольцо вокруг чёрного круга: dash [46,22], `lineDashOffset = −260·lt`.
- Радиоволны с вершины башни: 4 красные дуги, `r = 18 + ((1.4lt + k/4) mod 1)·230`, α и толщина линии затухают с фазой.
- Лозунг на полу «ПЕЙТЕ ЧАЙ!»: побуквенное «штампование» (k-я буква стартует через 0.045k с, за 0.12 с сжимается с 1.5× до 1), затем вся строка подпрыгивает волной `−10·max(0, sin(11lt − 0.8k))`; каждая 4-я буква чёрная.
- Два конца косынки слегка качаются `sin(9lt)·6`; пар над чашкой — три чёрные ломаные, идущие вверх.

**Персонажи**: комсомолка — красная косынка (локальные 13 точек головы, передний край сдвинут назад, чтобы была видна золотистая чёлка, сзади на шее узел с двумя треугольными концами), белая рубашка + красный треугольник галстука + красные манжеты, тёмно-серая длинная юбка (растровые тени). Кошка — оранжевый как вырезанная бумага `#e2741c` + кремовый, чёрные полосы 10px, хвост обведён пунктиром для тигрового окраса, глаза — квадратные с вертикальными зрачками-полосками.

**Палитра**: бумага `#e9dfc4`; красный `#c8231c`／`#8f1711`; чёрный `#151311`; кремовый `#f4ecd6`; светлые волосы `#e3b03e`／`#a87a1c`; оранжевый кошки `#e2741c`.

**Грабли**
- Краткая у «Й» в первой версии рисовалась над ячейкой буквы (y=−1.7u): в вертикальной надписи её перекрывала предыдущая буква, в лозунге на полу — подол юбки, на ревью читалось как «ЧАИ». Исправлено: вся буква рисуется в пределах 7 ячеек (часть И сдвинута вниз на 1.7 ячейки), лозунг тоже перенесён на отрисовку поверх персонажей (буквы плаката перекрывают людей).
- «А» в первой версии собиралась из двух противоположно наклонённых ножек + перекладины в одном path, пересечения гасились правилом nonzero, в вертикальной надписи читалось как «В». Заменено на fill по деталям.
- Базовая линия лозунга на полу в первой версии была на y=1060, нижняя половина букв уходила за кадр. Позиционирование по центру буквы через `translate(x, 990)`.
- Тень под скулами в первой версии слишком тяжёлая, после растрирования похожа на бороду. Тень в сером источнике должна иметь α вдвое ниже, чем при плоской заливке.

**Что ещё можно улучшить**: у Родченко типичнее «фотография человека + конус текста, расходящийся рупором». Можно заменить пар на красно-чёрный клиновидный конус текста, расходящийся от края чашки.
