# 23_dali · 1931 сюрреализм Дали («Постоянство памяти»)

> Источник: тест переноса B (выполнен независимым агентом, который только читал skill, 2026-10-04). Код сцены после объединения перенесён в `scripts/engine/scenes/23_dali.js`.

Имя файла во время эксперимента: `scenes/c2_dali.js` (около 235 строк). Медиана на кадр 47 мс (первый кадр 84 мс); разница кадров 4.6%.

**Пайплайн**
1. Фон разбит на три кэша, потому что тени должны оказаться посередине: `dali_bg` (небо, море, скалы, земля) → каждый кадр рисуются тени → `dali_wall` (обломок стены с окном + сухая ветка) → `dali_block` (каменный стол + табурет) → мягкие часы → персонажи.
2. **Объёмная заливка `vol(c, path, x0,y0,x1,y1, a, b, occl, blur)`**: заливка линейным градиентом, затем внутри clip через shadowBlur обводится тёмная кайма — внутренняя тень. Во всём ролике нет контурных линий, академическая округлость держится только на этом.
3. **Длинные тени**: силуэт каждого объекта проецируется на землю аффинным сдвигом, `setTransform(1, 0, −kx, ky, kx·yg, yg·(1−ky))`, yg — линия касания земли этого объекта (стена 700, стол / кошка 905, человек 930). Все силуэты сначала рисуются в один offscreen (чистый чёрный), затем накладываются целиком с α 0.55, blur 1.5px, чтобы тени не темнели в местах перекрытия. Clip оставляет только часть на земле (y > 594). `kx = 0.85 + 0.6·easeInOut(lt/1.2)`, за 1.2 с тени заметно удлиняются.
4. **Мягкие часы `softMap(o, sag)`**: локальные координаты диска (u,v) → экран. Часть с v ≤ fold лежит на поверхности (y сжат до 0.28–0.32); часть с v > fold свисает: `X = cx + u·(1 − flare·q)`, `Y = … + d·(0.62 + 0.3·sag) + центральный гауссов провис + sin-рябь`. Внешний обод, циферблат, 12 делений, две стрелки (выбираются вдоль отображения, превращаясь в мягкие линии), блик на сгибе — **всё идёт через одно и то же отображение**.

**Ключевые параметры**: `flare = −0.12`, отрицательное значение заставляет свисающую часть расползаться наружу, как мягкая ткань, нижний край круглый; положительное — сужается в рожок мороженого. drip 0.18–0.4. sag за 1.2 с растёт 0.1 → 1.4: в первой версии было 0.35→1.0, на ревью сказали «часы явно не текут». Трое часов: подоконник R72, край стола R88, сухая ветка R64 (fold −34, бо́льшая часть свисает). Скорость стрелок 4.5–6.5 rad/s.

**Мотивные движения**: трое мягких часов непрерывно провисают, стрелки вращаются с разной скоростью; слон на ходулях на горизонте (четыре тонкие ноги с разностью фаз π/2 шагают поочерёдно, коленный сустав на высоте 0.52 слегка сгибается, тело слегка подпрыгивает с 14Hz, на спине обелиск) сдвигается влево на 70px в секунду; 9 муравьёв ползают по эллипсу вокруг оранжевых карманных часов; длинные тени удлиняются; хвост кошки размягчается и свисает (кончик хвоста y + q²·34).

**Персонажи**: испанская девушка, светло-голубое длинное платье + белый отложной воротник, светлый пучок волос, без контурных линий, объём за счёт градиента + внутренней тени, черты лица — тонкие тёмно-коричневые линии. Кошка — градиентный оранжевый, полосы — полупрозрачной кистью с blur 2px (мягко), глаза — радиальный градиент; белая грудь заменена гладким эллипсом (606,768) 40×92, без `K.white`.

**Палитра**: небо `#22407c → #5f88bd → #e9dcae`; море `#8aa6b8 → #4f6f86`; скалы `#e8c27a / #9a6a34`; земля `#d2ad70 → #7a5129`; стена `#f4ead2 → #cdbf9f`; золото часов `#f0d27c / #9a7426`, циферблат `#f6efd6`.

**Грабли**
- В первой версии тени падали в сторону зрителя (ky>0 вниз) и целиком съедались нижним краем кадра. Солнце нужно ставить низко слева спереди, тени ложатся вправо назад (y′ = yg − ky·(yg − y)).
- Тени падают на землю и должны рисоваться под стеной и столом, поэтому фон нужно разбить на слои, а не кэшировать одной картинкой.
- Мягкие часы с flare>0 плюс увеличенный drip — это рожок мороженого.
- Фон у этого счётчика — тёмно-синее небо, изначально заданный тёмно-коричневый текст не виден, заменён на кремовый текст + тёмную тень.

**Что ещё можно улучшить**: персонажи всё ещё тяготеют к векторной иллюстрации, можно добавить более тонкие блики и рефлексы в тенях; лежащее на боку мягкое существо-«автопортрет» из «Постоянства памяти» можно сделать четвёртым мотивом.
