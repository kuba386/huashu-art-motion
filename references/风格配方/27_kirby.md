# 27_kirby · 1966 Серебряный век Marvel (Джек Кирби + четырёхкрасочная офсетная печать)

> Источник: тест переноса C (выполнен независимым агентом, который только читал skill, 2026-10-04). После интеграции код сцены перенесён в `scripts/engine/scenes/27_kirby.js`.

Имя файла в эксперименте: `scenes/k1_kirby.js` (255 строк). Около 20 мс на кадр, разница между кадрами 7,5%.

**Пайплайн: одна и та же геометрия рисуется дважды**
1. **Цветоделённый слой**: бумага `#f4ecd6` + плоская заливка + растр Бен-Дэй. На светло-голубой основе стены — точки C (pitch 9, r 2.7, 15°), на тёмно-синей основе пола — фиолетовые точки (pitch 9, r 3.2, 75°), кожа — красные точки (pitch 7, r 1.5, 75°). **Весь слой `drawImage(color, 4, 3)` = несовмещение красок**.
2. **Слой туши**: белый фон, каждая часть — «белая заливка → тень → чёрная обводка 6px». При композитинге накладывается на цветоделённый слой через `multiply`, белое = прозрачное. Белая заливка каждой части перекрывает линии предыдущих частей, поэтому остаются только видимые линии, visibleLines не нужен.
3. **Чёрные пятна теней + штриховка с растушёвкой (spotted blacks + feathering) в стиле Кирби**: свет идёт от окна (LIGHT=(-0.86,-0.5)).
   - Чёрный полумесяц: `path ∩ ¬translate(path, LIGHT·d1)`, d1=14. Способ: сначала `clip(path)`, затем `clip(…,'evenodd')` по «прямоугольнику на весь экран + сдвинутому path», затем чёрный fillRect.
   - Полоса растушёвки: тот же приём с d2=30 даёт полосу, внутри которой рисуются параллельные линии вдоль направления света (шаг 9px, толщина 2.6).
   - Параметры (d1/d2): юбка 16/34, торс 14/30, рукав 10/22, волосы 12/26, тело кошки 16/34, столешница 10/18.
   - Одна функция накладывает тень в стиле Кирби на любой Path2D.

**Анимация мотивных движений**
- **Kirby krackle**: скопление из 16–26 чёрных кругов. Расстояние распределено по `R·rnd^0.7`, чем ближе к центру, тем крупнее (`R·(0.05+0.2·(1-d/R))`), seed меняется с частотой 12fps, радиус пульсирует по `sin(18t+i)`. 6 скоплений движутся по S-образному энергетическому потоку за окном (`(k/6+0.42t)%1`); поток — полоса с оранжевой каймой и жёлтой сердцевиной + зубчатый край тушью. Пар над чашкой тоже сделан через krackle (4 маленьких скопления поднимаются вверх).
- **Линии скорости**: скорость подъёма чашки `|sin(min(1,lt/0.9)π)|`, под дном чашки тянутся 9 чёрных линий длиной 70–180·v, дрожат с частотой 12fps; за локтем две дуги движения.
- **Крупная звукоподражательная надпись SLURRP!**: с lt 0.52 выскакивает через `outBack`, шрифт `Bangers-400` 132px (×0.82); чёрная экструзия из 7 слоёв (каждый смещён на (0.8d,d)) даёт объёмные «кубиковые» буквы Кирби; на красных буквах верхние 46px через clip становятся жёлтыми (двухцветные буквы); подложка — жёлтая взрывная рамка с 26 зубцами; дрожание ±3px с частотой 12fps.
- **Раскадровка панелей**: главная панель 24..1534, правая панель — крупный план морды кошки, зрачки поднимаются вслед за `cup` (`lerp(14,-18,cup)`) и смотрят влево. Фон — пурпурная подложка + жёлтый растр + 44 сходящихся чёрных треугольника (меняются с частотой 12fps) + 6 скоплений krackle вокруг головы. Внизу плашка подписи «BUT THE CAT IS WATCHING!», в левом верхнем углу — «MEANWHILE, AT TEA TIME...». Счётчик оформлен как плашка подписи с жёлтым фоном, чёрной рамкой и смещённой чёрной тенью, размещён в межпанельном промежутке справа вверху.

**Персонажи**: красное трапециевидное длинное платье 60-х, белый воротник «Питер Пэн» (два эллипса), три чёрные пуговицы на планке, чёрный ободок (дуга эллипса в повёрнутой системе координат головы, толщина 11), загнутые наружу кончики волос (рисуются в хуке `skirt`, позади торса). Стул — кресло-тюльпан Сааринена.
