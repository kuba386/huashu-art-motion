# 17_ink · китайская живопись тушью се-и (Бада Шаньжэнь / Ци Байши)

> Источник: тест переноса A (выполнен независимым агентом, который только читал skill, 2026-10-04). Код сцены после объединения перенесён в `scripts/engine/scenes/17_ink.js`.

Имя файла во время эксперимента `scenes/01_ink.js` (313 строк). Разница кадров 0.45↔0.9 с — 3.3% (порог 24), медиана по соседним кадрам 0.62%, пар статичных кадров нет.

**Пайплайн** (противоположен эталону 09: бумага — основа, тушь только добавляется, а не заливает). В начале `lt += 0.12`, к кадру 0 уже положены первые несколько мазков, это не чистый лист (на ревью отметили, что белый первый кадр нельзя использовать как обложку).
Бумага сюань (кэш) → слой размывов: дальние горы бледной тушью, киноварное солнце → полосы тумана (размытые эллипсы цвета бумаги, сдвигаются по горизонтали) → пролетающая птичка → статичные мазки: окно, столик, линия пола, после написания кэшируются → ветви бамбука (листья в форме иероглифа 个) → креветки Ци Байши в свитке на стене → кошка: размыв жжёной охрой + густая чёрная тушь → девушка: размыв индиго + контур баймяо + складки одежды → тонкие нити пара → оттиск печати.

**Бумага сюань**
`P.texture('#efe6d0', scale .0025, amt 9, grain 7)`. Поверх накладываются 2600 коротких дуг-волокон бумаги: половина коричневых α.05–.13, половина светлых α.12–.27. Плюс радиальное виньетирование, к краям α.22.

**Кисть `brush(c, pts, {w, tone, dry, reveal, bristles, head, tail})`**
- Ряд точек сначала уплотняется Catmull-Rom, затем перевыбирается с равным шагом по длине дуги 4px (`KIT.resample`). Без перевыборки частота шума «сухой кисти» (фэйбай) меняется с длиной мазка.
- Нажим: `prof(q) = smoothstep(0,head,q) · (1−0.7·smoothstep(1−tail,1,q)) · (0.85+0.15·noise)`.
- Влажная сердцевина: весь мазок заливается ribbon, ширина `w·prof·(1−0.85·dry·q^0.8)`, α = tone×0.72. К концу всё тоньше — тушь заканчивается.
- Волоски кисти: каждый — одна **непрерывная** ломаная, поперечное смещение ±0.475w·prof. Когда шум `noise(k·1.9, i·0.09)` ниже `dry·q^1.2·0.95+0.05`, линия рвётся, и проглядывающая бумага и есть фэйбай.
- Грабли: в первой версии волоски рисовались «каждый маленький отрезок отдельным stroke + round cap», на стыках накладывались тёмные точки — выглядело как коленца бамбука или пеньковая верёвка. Обязательно: каждый волосок — один непрерывный path, butt cap.
- Параметры: оконная рама w14–18, dry .45–.6; столешница w22; складки одежды w4–6, dry .3–.4, tone .78; линия пола w5, dry .85, tone .35.

**Слой размыва `washLayer`**
- Форма сначала рисуется на scratch, затем через multiply переносится на бумагу, в два прохода.
- Внешний ореол: `blur(halo·(0.4+grow))`, α = haloA·grow.
- Тело: `blur(blur·(1.6−0.6grow))`.
- grow идёт от 0 до 1 по lt: в начале расплывается из ничего, затем внешний ореол продолжает медленно расширяться — это и есть «тушь расходится по бумаге».
- Девушка halo 12, α.6; кошка halo 9, α.78; дальние горы halo 14.

**Пустота (любай)**
- Белые части кошки (морда, грудь, лапы) вырезаются из охристого слоя через `destination-out`, проступает цвет бумаги. Это гораздо «туши», чем рисовать белым.
- Так же вырезается нижняя рубашка девушки с запахом.
- Лицо заливается цветом бумаги и обводится контуром баймяо 1.8px густой тушью.

**Цвет**
- Тушь `[16,14,12]`, через tone делится на пять тонов (жжёная .9 / густая .8 / плотная .6 / бледная .35 / прозрачная .15).
- Жжёная охра (кошка) `#c47a3c`; индиго (одежда) `#6f8aa0`, широкие рукава `#7d97ab`; гуммигут (светлые волосы) `rgba(226,170,52,.75)` multiply.
- Румяна-кармин только в трёх местах: пояс, бусина шпильки, точка на губах, `[190,40,40]`. Ещё киноварное солнце `#d8553f`, печать `#c4281e`.

**Мотивные движения**
- **Написание в начале**: lt 0→0.45, у каждого мазка `reveal = ss(d, d+l, lt/0.45)`, пишутся по очереди: окно, столик, бамбук, кошка, человек.
- Бамбук: основная ветвь бледной тушью с коленцами, качается вокруг (835,70) по `sin(2.9t)·0.11`, к кончику сильнее. 5 групп листьев «个» по 3 листа (L110, w15), колыхание `sin(7t+g)·0.2`.
- Полосы тумана: 4 эллипса цвета бумаги, blur 14, α.72, сдвигаются по горизонтали со скоростью 150–270px/s, дальние горы то видны, то скрываются.
- Птичка в духе Бада Шаньжэня: проносится справа от окна со скоростью 420px/s, крылья в два мазка, около 8 взмахов в секунду (`sin(52·lt)`).
- Креветки Ци Байши (две в свитке, 1.45×): 6 сегментов бледной тушью + один мазок густой тушью посередине головогруди, два длинных и два коротких уса — бегущей волной, клешни из трёх длинных сегментов, изгиб тела `sin(7t)·0.12`, плывут вдоль кривой.
- «Белый глаз» Бада Шаньжэня: точка зрачка кошки упирается в верх глазницы — «белки глаз к небу».
- Оттиск печати: lt 0.3–0.4 сжимается с 1.5× до 1×, ставится через multiply; надпись белыми знаками «白石».

**Грабли**
- Статичные мазки во время написания рисуются в реальном времени, после завершения единожды кэшируются в `ink_static`, иначе каждый кадр рисуются тысячи волосков.
- В первой версии путь птички проходил через заросли бамбуковых листьев — её не было видно; перенесена выше полосы тумана, y≈470, только тогда стала читаться.
- Размыв идёт через multiply и прозрачен, поэтому линия туши подоконника просвечивает сквозь уши кошки, ножки стола — сквозь юбку, на ревью это прочитали как «неправильный порядок слоёв». Исправление: внутри силуэтов кошки и одежды сначала кладётся слой цвета бумаги (clip, затем drawImage бумаги), и только потом размыв. Это равносильно тому, чтобы «заранее оставить это место» на бумаге.
