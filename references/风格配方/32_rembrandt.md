# 32_rembrandt · 1642 Светотень Рембрандта

> Источник: тест переноса D (выполнен независимым агентом, который только читал skill, 2026-10-04). После интеграции код сцены перенесён в `scripts/engine/scenes/32_rembrandt.js`.

Имя файла в эксперименте: `scenes/r1_rembrandt.js`, около 47 мс на кадр.

**Пайплайн**: подмалёвок в светлом состоянии (комната, ромбовидное окно со свинцовыми переплётами, турецкий ковёр на столе — в цветах «полного освещения») → фон перерисовывается крупными коричневыми мазками, затем размывается на 2.2px и накладывается на 75% (растёртый подмалёвок) → ковёр на столе отдельным слоем, мелкими мазками → персонаж: плоская заливка + градиенты объёма + мелкие мазки → обработка «потерянного края» персонажа → **карта освещения multiply** → осветление оконного стекла через screen + проплывающие тени облаков → пастозные мазки щетинной кистью → пламя свечи, пыль в луче света, пар → кэшированный слой кракелюра, зерна, виньетки + золотисто-коричневая лессировка через soft-light.

**Ключевые параметры**
- Карта освещения: базовый цвет rgb(30,21,13), что соответствует окружающему свету 0.13. Наложение через lighter:
  - Луч света: клиновидный многоугольник, размытие 40px, кэшируется, α 0.8–0.95.
  - Само окно: r330.
  - Световое пятно на лице: r250 α0.95. Грудь: r230 α0.55. Кошка: r240 α0.8. Столешница: r280 α0.6.
  - Свет свечи: r190+40·fc, α 0.6+0.4·fc.
  - «Отделяющий свет» на стене за девушкой: r300 α0.35. Рембрандт часто высветлял стену за тёмной стороной фигуры, чтобы отделить её от фона.
  - После наложения весь кадр через multiply.
- Мерцание: `flick(t) = 0.5·noise(2.2t) + 0.25·noise(6.5t)`; центр светового пятна дрейфует по noise(0.9t) на ±14px; тень облака `cloud = 0.5 + 0.5·sin(2.2t − 0.6)` умножает свет окна на ×(1 − 0.35·cloud), одновременно тёмное радиальное пятно пересекает стекло со скоростью 260px/s.
- Мазки фона: cell18, len54, w16, jitter 6, угол −0.9 + 1.6·noise(0.003); палитра mixBase 0.7.
- Потерянный край: слой персонажа сначала рисуется полностью непрозрачным с blur(2.4px), затем поверх кладётся чёткий слой с α0.62. Тёмная сторона растворяется в фоне, а черты лица остаются узнаваемыми.
- Пастозные мазки (щетинная кисть): один мазок = round(w/1.3) параллельных тонких щетинок, у каждой яркость ±17, концы случайно укорочены на 0–25%, толщина 1.4–2.6; снизу тень с α0.28; сверху разбросаны 2+w/3 световых точек. Только на освещённых местах: светлые волосы, вырез воротника, фарфоровая чашка, жемчуг, белая грудка кошки, макушка кошки.
- Накладные слои: кракелюр α0.28×0.28; зерно density 0.05 α0.12; виньетка 0.75; soft-light rgba(200,140,60,.35).

**Анимация мотивных движений**: пламя свечи (по noise наклоняется влево-вправо, высота прыгает), свет окна затемняется тенью облака и восстанавливается, 70 пылинок в луче света (видны только внутри луча, мерцание каждые 24 кадра), подъём чашки, пар. Площадь движения 8.0% (0.45↔1.0s).

**Подводные камни**
- Пастозный мазок в первой версии рисовался тремя аккуратными линиями «смещённая тень + основной мазок + светлый гребень» и читался как белая наклейка/пластырь. Только после перехода на щетинную кисть стал похож на краску.
- Копирование локальной области исходника обратно (`drawImage(b, x,y,w,h…)`) приносит вместе с ней фон без мазков, образуя прямоугольные заплатки. Реквизит нужно рисовать отдельным слоем после мазков, а не копировать области.
- Зерно density 0.12 / α0.22 покрывает лицо грязными точками, 0.05 / 0.12 — в самый раз.
- Руку нужно рисовать до чашки, иначе эллипс руки перекрывает фарфоровую чашку. В drawGirl порядок «рука → чашка → большой палец»; при самостоятельной перерисовке соблюдайте этот порядок.
