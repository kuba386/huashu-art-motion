# 20_dunhuang · фрески Дуньхуана (пещеры Могао · расцвет Тан)

> Источник: тест переноса A (выполнен независимым агентом, который только читал skill, 2026-10-04). Код сцены после объединения перенесён в `scripts/engine/scenes/20_dunhuang.js`.

Имя файла во время эксперимента `scenes/04_dunhuang.js` (215 строк). 0.45↔0.9 с — 6.6%, медиана по соседним кадрам 1.98%.

**Пайплайн**
Красноземельный грунт (кэш): `P.texture #a5452f`, dark `#7a3020`, плюс редкие выцветшие круглые цветочные медальоны, сверху кайма из вьющихся трав + треугольные свисающие драпировки (чередование сине-зелёного, белого, красного + золотые бусины) → окно = небо азуритового цвета: благие облака, апсара (фэйтянь) → оконная рама с орнаментом вьющихся трав → пол из плиток с лотосами (кэш) → низкий столик с арочными проёмами (куммэнь), масляная лампа → кошка → девушка (танская дарительница) → пар облачными завитками → небесные цветы → покрывающий слой.

**Линия и цвет**
- «Железная проволока» (тесемяо): равномерная ширина 2.6px, цвет `#5a2414`. Лицо — более красным `#8a3a24`.
- Минеральные пигменты: красная земля `#a5452f`, малахит `#3f8f6e / #6ab08e`, азурит `#2f5f8f / #5a86b0`, белый `#ecdfc4`, золото `#d8b05a`.

**Танский костюм**
- Юбка с чередующимися полосами: красная основа, наклонные трапециевидные зелёные полосы, одна на каждые 44px, книзу расходятся по x.
- Короткая кофта азуритового цвета, белый запахивающийся воротник, высокий красный пояс.
- Высокая причёска: над headTop накладываются два эллипса, плюс золотая шпилька и три цветка в волосах.
- Макияж: хуадянь (красный четырёхлепестковый цветок на лбу), сехун (красная дуга на виске), точечные губы, «брови-мотыльки».
- Чашка — селадон печей Юэ.

**Шарф пибо `shawl(pts,w)`**
- Ряд точек бегущей волной → ribbon, плюс узор белой пунктирной линией и красные точки.
- Часть за спиной: `x = back + 230q + 64q·sin(4.2q − 5.5t)`, последние 30% поднимаются вверх.
- Передняя часть обвивает руку и свисает.
- Грабли: в первой версии поперечный размах был всего 18–34px и почти вертикальный — выглядело как вертикальная перекладина стула. Поперечное смещение должно быть больше 200px, плюс подъём конца — только тогда читается как развевающийся шёлк.

**Апсара (фэйтянь)**
- Лежит горизонтально головой влево, 1.35×, пролетает мимо окна со скоростью 300px/s.
- Три ленты бегущей волной, одна из них поднимается от плеча дугой над головой и откидывается за спину — эта большая дуга самая узнаваемая форма апсары.
- Нимб, причёска, поднос с цветами.
- Благие облака — круглые клубы + сужающиеся облачные хвосты, плывут со скоростью 40–76px/s.

**Покрывающий слой (состаривание)**
- Всё целиком: смешивание `saturation` с α.3 для выцветания, затем через multiply слой светлой земляной текстуры α.5.
- Попиксельное осыпание: там, где `fbm(x·.0032)+0.12·noise(x·.03) > 0.3`, проступает бело-серый грунт `#d8c6a2`, 0.28–0.3 — тёмная линия края осыпи.
- Окрестности двух лиц — защищённая зона, без осыпания.
- 500 трещин случайным блужданием, сверху 380px градиента копоти.
- Грабли:
  - При частоте шума осыпания .006 получалась сплошная россыпь «кунжутных» пятнышек, похожих на грязь. Только после снижения до .0032 и повышения порога получились отдельные куски осыпи.
  - В финальной версии кошка (380–720, 530–920) и девушка (1070–1530, 240–950) — защищённые зоны, осыпается только фон.
  - α сехуна снижена до .32, иначе похоже на шрам.
  - Нимб апсары в первой версии был сплошным зелёным кругом и читался как «надувной круг для плавания» — сделан полупрозрачным α.28 с тонкой линией.
  - При цвете кошки `#c8843a` после выцветания она становилась буро-жёлтой — заменено на `#e08a3a`; добавлен поворот головы `look: sin(2.6t)`, дыхание усилено в 2.5 раза, иначе на всём отрезке двигался только хвост.

**Мотивные движения**
- Небесные цветы: 30 четырёхлепестковых цветков вращаются и падают, переворачиваясь.
- Масляная лампа: пламя прыгает `1+0.12sin(17t)+0.08sin(29t)`, плюс ореол.
- Чешуйки краски: 10 штук отрываются от края осыпи, переворачиваются и падают по параболе.
- Колокольчик на ошейнике кошки качается.
