# 01_cave · 40 000 лет до н. э., пещерная наскальная живопись (чистый код)

Файл: `scenes/01_cave.js` (около 330 строк). Итоговая производительность: warm max 22ms / mean 21.1ms, cold (построение кэша) выполняется при boot движка; проверка детерминированности пройдена; разница движения 0.2↔0.7s — 3.9% пикселей.

## Конвейер
1. **Скальная стена (полностью в кэше, `cave_relief`/`cave_bg`)**
   - Поле высот считается в половинном разрешении 960×540: `fbm(x·0.0022,4oct)·1.0 + fbm(x·0.011,3oct)·0.16 + noise(x·0.05)·0.03` (координаты — в пикселях полного разрешения).
   - Нормаль получается конечными разностями ×52, источник света L=(-0.55,-0.62,0.56) (слева сверху), `shade = clamp(0.5+(dot-0.56)·0.9)`; базовый цвет смешивается между `#ce925a` (светлая охра) / `#6e4426` (тёмная) / `#b6643a` (красные пятна) двумя слоями низкочастотного fbm, затем ×(0.72+shade·0.55). Увеличение на весь экран с плавной интерполяцией → мягкий рельеф.
   - Накладываются два слоя `P.grain` (тёмный: плотность 0.22, α0.32; светлый: 0.10, α0.28) для зерна; 10 трещин случайным блужданием (поворот на шаге ±0.45rad, длина шага 14–40px, 12% вероятность ветвления), под тёмной линией подкладывается светлая со смещением +1.6px → ощущение процарапанности.
   - Виньетка: радиальный градиент r 260→1180, внешнее кольцо α0.8; статичный тёплый свет в центре через lighter (α0.36) освещает только стену.
   - **Грабли: при большом коэффициенте среднечастотного члена relief (0.35, нормаль ×60) вся стена превращается в камуфляж / дюны, и фигуры с наложенной текстурой выглядят как в камуфляжной форме**. Только после снижения средних частот до 0.16 и нормали ×52 стало похоже на камень.
2. **«Краска въелась в камень»**
   - Все фигуры рисуются единым способом `shape()`: сначала обводка **fuzz-паттерном** (редкие угольные точки, ширина 2lw+7) → затем **ink-паттерном** (угольно-чёрный, 7% случайных дыр + крупные дыры там, где шум >0.58, ширина 2lw) → в конце плоская заливка закрывает внутреннюю половину. Результат = сплошная угольная линия + напылённый рваный край, а порядок painter естественно решает перекрытия (рука закрывает линию одежды).
   - «Кипение» угля: два паттерна 256 раз в 1/9 s случайно сдвигаются через `pattern.setTransform`; геометрия неподвижна, прыгает зерно — дешевле, чем дрожание путей, и без деформаций.
   - После отрисовки всего красочного слоя поверх через `source-atop` кладётся `cave_figtex`: тени камня → чёрный α(0.5-v)·150, светлые места → тёплый белый α(v-0.5)·50, тёмное/светлое зерно, низкочастотные пятна сухой/влажной краски α≤70. **У красочного слоя только одно полноэкранное композитирование**, поэтому 19ms.
   - Все заливки — непрозрачные плоские, цвет «пачкается» текстурой; не накладывайте краску через multiply — мел (белое у кота) исчезнет.
3. **Негативные отпечатки ладоней / лап**: на временном холсте 320² гауссово напыление точек (σ46·s, 3200 точек α0.15–0.6 + σ28, 1400 точек), затем `destination-out` сплошной маской формы руки, в конце маска с α0.3 заливается `#f6e2bc`. **Форму руки нужно заливать в маску по частям**: если добавить эллипс ладони и капсулы пальцев через addPath в один Path2D и залить разом, то в местах с противоположным направлением обхода подпутей nonzero их взаимно погасит и появятся дыры (наступили в r4).
4. **Свет огня**: каждый кадр один слой радиального градиента, центр (1000+40·noise(t·3.1), 540+26·noise(t·2.3)), интенсивность `0.13+0.09·noise(t·8.5)+0.04·sin(21t)`, **композитирование через overlay** (α=интенсивность×2.6). Снаружи ещё одна виньетка, «дышащая» в противофазе огню. Грабли: сначала использовали lighter — золотые волосы девушки и шкура выцвели до розово-белого и потеряли насыщенность охры; после замены на overlay цвета вернулись.
5. **Тлеющие искры**: три группы `P.particles` (слева 0–360 ×11, справа 1540–1920 ×12, в центре ×5), y дрейфует от 1110 к 120, life 5.5s; яркое ядро r 2.2–4.6 + ореол в 3.2 раза больше, мерцание `|sin(6t+1.9i)|`, `sin(q·π)` для плавного появления и исчезновения, композитирование lighter.

## Анимация мотивов
- **Две позы бизона/лошади**: `ph = floor(t·60/7)%2` (смена каждые 7 кадров), два набора координат концов ног (вытянуты / подобраны), голова вокруг точки шеи ±0.07rad, всё тело по y чередует -3/+1px; лошадь и бизон в противофазе. Ноги — только угольные линии (как в оригинале), тело — залитый силуэт + тёмная растушёвка 22px вдоль спины (светотень в духе Ласко).
- **Чашка в руке**: траекторию чашки из RIG не использовали (стол → рот; точка стола оказывается у груди девушки, не похоже на оригинальное «вытянутая рука держит чашку в воздухе»). Своё: `hold=(1084,506)` → `mouth=HP(1224,380)`, прогресс `k = choreo(max(0,lt-0.95)).cup` (кривая choreo целиком сдвинута на 0.95s, чтобы совпасть с подъёмом чашки на 58-м кадре оригинала), рука через `RIG.ik2(G.A.shoulder, cup+(34,10), 170,128,-1)`; `RIG.girl({cup:k})` по-прежнему отвечает за запрокидывание головы и лёгкий подъём при глотке. k достигает 1 при lt≈1.85 (конец перехода T01).
- **Пар**: три угольные линии `x0 + sin(13q − 11t + 1.3j)·6`, высота 58px, следуют за чашкой.
- **Кот**: якоря head/eyes/nose/earInner/stripes/tailPts из RIG.cat + своё грушевидное тело, белая грудь, белые передние лапы, дуга бедра; хвост = трёхслойная обводка fuzz/ink/оранжевый + поперечная полоса на каждых 4 точках выборки; моргание из choreo.blink.
- **Размер кота (доработка после проверки)**: в исходном размере RIG.cat кончики ушей на y≈535 упираются в нижний край рамки росписи (550). Весь кот масштабирован через трансформацию холста с якорем в точке лап (540,905) до 0.86 (translate→scale→translate, сам RIG.cat по-прежнему s=1); кончики ушей опустились до y≈582, до низа рамки около 30px, лапы на месте. Толщина линий тоже ×0.86 — разницы не видно.
- **Заголовок**: `Kalam-700` 78px letterSpacing 7, горизонтально масштабирован до ширины 930px, `#9b2a18`, рисуется в красочный слой (тоже впитывает текстуру камня). α = t<0.933 ? 1 : 1-(t-0.933)/0.2.

## Доработка по количеству движения (метрика проверки: статичный отрезок, кадры 21–84, средняя покадровая разница 480×270)
Копия 0.62 против оригинала 0.86 — слишком статично. Добавлялись только локальные движения, без полноэкранного мерцания:
- Свет огня: интенсивность `0.14+0.11·noise(9.5t)+0.04·sin23t+0.03·sin37t`, блуждание центра ±60/±36px (было ±40/±26). Пробовали больше (±0.16, ±90px) — уходит в 1.22, кадр «трясётся», откатили.
- Искр 28→49 (слева 20, справа 20, центр 9), яркое ядро r 2.6–5.4, ореол α0.32, в 3.6 раза больше, мерцание `0.3+0.7|sin|`.
- Отпечатки ладоней мерцают: на каждый наложен тёплый радиальный градиент r=105 (lighter), α=0.2·clamp(0.5+0.9·noise(7t+3.7k)), у каждого своя фаза.
- Тряска бизона/лошади ±3 → 9px по вертикали, ±3px по горизонтали, качание головы ±0.12rad.
- Мелкое движение головы кота (по кадрам оригинала 65–81): lt 1.08–1.35 с огибающей `sin(πq)`, вокруг точки шеи (596,680) поднимает голову с поворотом −0.16rad, look у RIG.cat сдвигается на 1.5, уши мелко дрожат на 60Hz ±0.06rad.
- Результат: **0.62 → 1.06** (оригинал 0.86); max 22ms на кадр.

## Адаптация девушки под эпоху
Силуэт красной охрой `#9c3520` (лицо / шея / руки / голени), в профиль остаётся только один миндалевидный глаз (кремовый белок + чёрный зрачок + одна ресница, при моргании превращается в дугу) — именно этот штрих ключевой для «девичести»; золотые волосы — заливка жёлтой охрой `#cf8f2c` + 6 волнистых прядей `#6e3c0e` (амплитуда растёт с длиной), контур тоже волнистый; нижняя половина прядей постепенно перестаёт следовать за поворотом головы (функция HB), чтобы при запрокидывании головы на глотке не мотало всю шевелюру. Одежда из шкуры до колен = G.torso + свой подол (каждые 15px зубец ±16px, рваный мех), `#b06a2c` + 26 леопардовых пятен «круглое пятно + 7 точек» + 18 коротких штрихов меха; швы скрыты приёмом «сначала обвести края обоих кусков, потом залить их вместе».

## Что ещё можно улучшить
- Тело девушки — реалистичные кривые из RIG, «слишком гладкие» для настоящей наскальной фигуры; более первобытный подход — прорядить точки контура до 12–16 и усилить ручное дрожание.
- Рельеф стены статичен, огонь меняет только яркость, но не направление теней; чтобы по-настоящему «рельеф шевелился в пляшущем свете», нужны две карты shade с разными направлениями света и интерполяция между ними по огню (+1 полноэкранное композитирование).
