# Новые переходы из тестов переноса (A–D)

<!-- Из теста переноса A -->
## Переходы (новый блок в конце `transitions.js`)

| Переход | Вход в | Приём и параметры |
|---|---|---|
| `goldLeaf` 0.5s | Климт | Квадраты 72px. Порядок key = расстояние до головы девушки (1300,380)×0.78 + азимут×0.12 + случайное×0.08, поэтому золотые листы укладываются по спирали. Для каждого квадрата q = (1.32p−key)/0.32: при q<0.5 лист сусального золота опускается на место с 1.3× и вращением, золотой градиентный блик движется вместе с q, поверх тиснение спирали, глаза или концентрических кругов; при 0.5<q<1 проступает B, золотой лист гаснет. |
| `screamWarp` 0.5s | Мунк | Старое изображение изгибается построчно синусоидой, амплитуда 70e. Фронт волны `y = lerp(−180, H+220, e) + 80sin(x·.0055 + 7p)` идёт сверху вниз, выше фронта — новое изображение (амплитуда изгиба 60(1−e) постепенно затухает). На фронте 4 цветные полосы по 26px: `#b82a1e #e2541c #f08a24 #f4c03a`. |
| `apsara` 0.5s | Дуньхуан | Фронт `x = lerp(W+260, −300, e) + 110sin(y·.006 + 5p)` проходит справа налево, справа — новое изображение. На фронте 3 ленты (малахит, красная земля, азурит, ширина 44/38/32, бегущая волна, узор белым пунктиром). Слева от фронта осколки старого изображения (прямо берутся блоки пикселей A) переворачиваются и падают по параболе — это «осыпание старой росписи». |
| `dotBloom` 0.48s | Кусама | Гексагональная сетка 58px, от кошки (540,760) по расстоянию по очереди вырастают точки (outBack, максимум 0.74 шага — ровно покрывают экран), внутри точек через clip — новое изображение. Невыросшие точки имеют белую обводку, постепенно гаснущую. |

## Переходы `transitions_b.js`

| Вход в | Имя | Приём | Параметры | На кадр |
|---|---|---|---|---|
| Дали | `melt` | Старое изображение провисает вертикальными столбцами по 4px (`sag = 0.22·edge·e`, с растяжением 0.3); новое изображение выше уровня жидкости edge(x), edge = общая линия опускания (−160 → H+40, easeInOut) + 26 капель с круглыми концами (ширина 10–32, длина 60–280, профиль `(1−u²)^0.3`, у каждой своя начальная фаза) + sin-волна; уровень жидкости обведён тёмным краем (blur 3) + блик | 0.36s | 86ms |
| Хоппер | `sunShaft` | Старое изображение через `multiply` холодным зелёным `rgba(70,120,110, 0.7·min(1,2p))` погружается в тень; световая плоскость со скошенным краем (наклон 260px) правым краем проходит по всему экрану, внутри — новое изображение + тёплый свет через `screen` (0.45 → 0, уходит на p 0.6–1) + косая тень оконного переплёта, движущаяся вместе с ней; на переднем крае — светлая кромка | 0.34s | 76ms |
| Гибли | `bleed` | 5 цветовых пятен раскрываются по очереди по t0 (первым — окно), радиус `q·1400·k`, q=easeInOut(seg(p,t0,t0+0.66)), граница `R·(1 + 0.28·fbm(угол) + 0.05·sin 9a)`; снаружи светлый ореол 70px blur 18 (вода приходит первой), внутри — новое изображение, по краю коричневый след воды 5px через `multiply`. α светлого ореола и следа воды умножаются на (1−q) | 0.38s | 127ms |
| Вейпорвейв | `vhs` | В первой половине старое, во второй новое; на отрезке p 0.38–0.62 «потеря кадровой синхронизации» — всё изображение прокручивается вверх + чёрная полоса 40px; полосы разрыва случайной высоты 6–54px берутся из A/B (вероятность взять B = p), горизонтальный сдвиг ±130·sin(πp); две одноканальные копии — пурпурная / голубая — накладываются через `screen` со сдвигом ±14; 160 линий «снега» | 0.30s | 88ms |

Общее: каждый переход — «физический процесс нового стиля», а не универсальная шторка: таяние — это жидкость, Хоппер — свет, акварель — вода, VHS — магнитная лента. При проектировании сначала задайте вопрос: «каким физическим образом появится изображение в этом стиле?»

## Переходы (`transitions_c.js`)

| Вход в | Имя | Приём и параметры |
|---|---|---|
| Моне | `ripple` | (знаменатель расстояния 1700, с p>.7 добавляется проявление, чтобы при p≈.85 углы уже были чистыми) Старое изображение сдвигается горизонтальными синусоидальными полосами по 6px, `dx=sin(0.045y−26p)·46·sin(π·min(1,1.2p))·(0.4+|y−cy|/H)`, как взбаламученное отражение. Новое изображение проступает через clip из 3600 **горизонтальных коротких мазков-эллипсов** (длина 40–110, высота 9–17), расходящихся кругами по эллиптическому расстоянию до чашки (1000,600) (y×1.9). На фронте 3 кольца светлых пунктирных эллипсов, dashOffset следует за p; в середине мерцают 140 горизонтальных линий бликов на воде. При p>.85 добавляется слой проявления. |
| Сёра | `pointill` | Сетка pitch 14: точки растут от 0 до r=6.4 (первые 30%), старое изображение под точками бледнеет до цвета бумаги. Момент смены цвета каждой точки `0.5·(0.6x/W+0.4y/H)+0.25·hash+0.15`, сначала левый верхний угол, со случайностью; в момент смены цвета точка увеличивается в 1.35 раза — «подпрыгивает». При p>.6 под точками проявляется новое изображение, при p>.7 точки втягиваются. Каждый кадр нужен один getImageData для A и один для B. |
| Матисс | `cutouts` | Лист кобальтово-синей бумаги шириной 1100px (левый и правый края — неровный sin-срез) проходит справа налево, тень (14,10) blur 12. На бумаге 260 следов гуаши, приколоты белые / жёлтые водоросли (стебель + 7 пальцев), жёлтые / розовые 6-лучевые звёзды (вращаются по p), красные кружки, у каждого своя тень. Позади правого края бумаги уже новое изображение. |
| Харинг | `radiant` | V-образный танцующий человечек, масштаб `s=0.15·320^easeInOut(p)`, увеличивается с чашкой как началом координат. Сначала «обводка 30px чёрным + заливка чёрным» даёт внешний контур, затем в offscreen конечности заливаются белым, `source-in` с новым изображением — получается новое изображение внутри тела; снаружи 16 радиальных линий прыгают на 8fps; с p>.82 добавляется проявление. В первой версии экспонента была слишком медленной (`0.08·40^…`, первые 80% времени высота всего 300px, в конце жёсткая склейка); во второй версии `0.15·120^…` в конце всё ещё оставались промежутки, закрыть их можно было только проявлением примерно в 1 кадр — на ревью признано мигающим кадром; финал — `s=0.15·320^easeInOut(p)`. |

**Общий опыт по переходам**:
- Переходы, которым нужны пиксели (пуантилизм, рябь на воде), делают getImageData для A/B каждый кадр, около 10 мс за раз — приемлемо.
- Для переходов типа «новое изображение спрятано внутри фигуры»: если фигура — объединение нескольких частей, не используйте `clip(объединённый Path2D)`: подпути с разным направлением обхода взаимно гасятся в дыры. Вместо этого заливайте белым в offscreen, затем `source-in`.

## Переходы (раздел D в конце `transitions.js`)

| Переход | Фирменный приём нового стиля | Приём и параметры |
|---|---|---|
| `irisFilm` Рембрандт→rubber hose | Ирисовая диафрагма мультфильмов 30-х + старая плёнка | ①p<0.5: к старому изображению постепенно добавляется `sepia(q) grayscale(0.7q) contrast(1+0.3q)`, чёрная диафрагма сжимается к краю чашки (1236,420), R = R0·(1 − easeIn(q)), R0 — расстояние до самого дальнего угла ②p≥0.5: новое изображение раскрывается по R0·outBack(q) ③окружность из 48 сегментов, на 12fps добавляется дрожание руки ±1.5% ④на всём протяжении поверх — мерцание плёнки, царапины, пыль |
| `lampGlow` rubber hose→театр теней | Зажигание лампы за экраном | ①старое изображение multiply rgba(70,34,12, min(1, 2.2p)) затемняется, будто гаснет свет ②новое изображение проступает через радиальную маску destination-in (внутри 0.55R сплошная, внешний край прозрачный), R = 1500·inOut(seg(p, .12, 1)), с дрожанием пламени ±7% ③тёплый ореол lighter sin(πp) плюс маленький огонёк |
| `flareSweep` театр теней→Макото Синкай | Засветка, проход света | Наклонная (k=0.35) граница проходит от −500 до W+700 (inOut). Слева новое изображение, справа старое. На границе 3 слоя световых полос lighter: ширина 520 α0.55 тёплая, 160 α0.85 белая, 60 α0.6 голубая. Плюс горизонтальные нити, 40 световых частиц, 3 шестиугольных блика |
| `blueBrush` Макото Синкай→голубой период | Цвет вытягивается + широкая сухая кисть | ①на старое изображение через смешивание `color` накладывается rgba(45,90,148, min(1, 2.2p)), остаётся только синий; затем multiply затемняет ②6 широких мазков (каждый высотой H/6+90) с чередующимся наклоном ±18 по очереди проходят слева направо, старт смещён на 0.07. Головка кисти — квадратичная кривая, верхний и нижний края с синусоидальным дрожанием 6–7px ③в 80–280px за головкой 26 линий щетины с тёмно-светлым градиентом (краска ещё не растушёвана) |

Общий порядок проектирования перехода (рекомендуется внести в слой 3 документа 02): найти физический процесс нового стиля, который «появляется, зажигается, проходит» → сначала этим процессом «заразить» старое изображение → новое изображение проступает из формы этого процесса → на долю такта наложить кратковременную подсветку или перелёт.
