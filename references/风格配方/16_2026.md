# 16_2026 · 2026 плоская векторная иллюстрация + финальная шутка всего ролика

Вся игра персонажей записана через **номер кадра всего ролика `F = t*60`**, ключевые числа построчно переписаны из `../拆解/分镜表.md` §4 — так удобно покадрово сверять с оригиналом.
Контактные листы для сравнения (слева оригинал | справа воспроизведение): `../渲染/16_2026/cmp_E1…E4_*.jpg`, фрагмент `clip_2026.mp4` (10.8–15.06 с).

## Стиль изображения (плоский Dribbble + зерно)
- Однотонные плашки, без обводки; объём передаётся только «плашками того же цвета на тон темнее» (светлый косой блок на свитере `#f08b7d`, бедро кошки `#f3ad4c` + тёмная дуга по краю).
- **Зернистый пуантилизм `stipple()`**: внутри формы разбрасываются квадратные точки 2px, плотность — функция положения: розовый круг `0.12 + 0.75·clamp((y-cy+120)/420)` (чем ниже, тем плотнее), светло-фиолетовый блок плотнее к правому нижнему углу, солнце плотнее к правому нижнему углу. Вся статика уходит в кэш `fl_bg`.
- После отрисовки слоя персонажей поверх через `source-atop` кладётся статичная текстура зерна (5% тёмных точек α70, 3.5% светлых точек α90) — зерно ложится только на персонажей.
- Световой конус: 26000 точек, ширина линейно растёт по y 56→150, прозрачность убывает по y, к центру плотнее; кэшируется в текстуру 340×420 и качается вместе с люстрой вокруг (1010,0).

## Девушка (собственные позы на базе RIG)
- Опорные точки торса / шеи: `RIG.girl({s:1.12})`; для головы ещё раз вызывается `RIG.girl({s:1.344, dy:43.7})` — это равносильно увеличению головы в 1.2 раза вокруг точки шеи, пропорции большой головы плоской иллюстрации. Лицо, чёлка, задние волосы, пучок, опорные точки глаз / губ / ушей берутся из этого вызова.
- Руки: `RIG.ik2(плечо, цель, 150, 140, -1)`, три набора целевых точек смешиваются по прогрессу: печать на клавиатуре (обе руки над клавиатурой поочерёдно поднимаются и опускаются на 7px с 22 rad/s) → поглаживание кошки (688–704, ближняя рука рисует маленькие круги по спине кошки) → возглас удивления (791–798, `ease.outBack` поднимает руки к подбородку, пальцы растопырены).
- Мимика: закрытые глаза-дуги + улыбка (<686) → глаза-точки с бликом, маленький рот «o» (с 686, «o» выскакивает через outBack) → большие глаза + широко открытый рот + язык (с 791) → после кадра 838 прищур «<» (в финальном кадре оригинала глаза тоже закрыты).
- Линии напряжения: 3 штуки, расходятся от макушки вперёд-вверх, длина выскакивает через outBack; цвет 793 бледно-розовый → 796 полностью красный (интерполяция RGB); 830–888 каждые 2 кадра случайное дрожание ±2.5px, голова синхронно дрожит на ±2px.
- Штанины / носки / обувь нарисованы вручную (в RIG длинное платье).

## Кошка (библиотека поз + интерполяция)
Каждая поза — набор локальных ключевых точек (смотрит вправо, начало координат = центр масс): тело 10 точек, белая грудь 6 точек, эллипс бедра, 3 сегмента полос на спине, голова, две передние лапы, задняя лапа, 4 точки Безье хвоста, gy (от подошв до центра масс).
Позы: `SIT_F` (сидит на полу, измерено по оригиналу на 10.95 с), `SIT_T` (сидит на столе; в оригинале смотрит влево, после замера зеркально сохранена вправо), `LEAP` (вытянута по горизонтали), `LAND` (передние лапы вниз). `mixPose` делает lerp по каждому значению.
Преобразование: `translate(центр масс) → rotate [вокруг подошв или вокруг центра масс] → scale(dir·sx, sy)`, сжатие и растяжение — всегда вокруг подошв, поэтому при приседании лапы не отрываются от пола.

Если считать прямо по координатам без наклона, после наклона на 0.38 rad лапа уходит вниз на 60px и втыкается в стол.

## Чашка и разбивание
- x чашки: линейная интерполяция по 16 измеренным точкам раскадровки (744:981 … 796:801); на 790–796 начинает отклоняться наружу на -0.12.
- Падение 796–815: Catmull-Rom по 9 измеренным центрам (измеренная гравитация ≈1.75px/кадр²), поворот `-0.12 - 2.3·q^1.3`; позади 6 капель кофе берут прошлые положения чашки с интервалом 1.3 кадра, чем раньше — тем мельче.
- 815 удар о пол: 7 радиальных линий удара гаснут за 8 кадров; два крупных осколка летят по параболе Лагранжа через три точки раскадровки (818/824/834), после приземления на 834 останавливаются; 9 мелких осколков по параболам, каждый останавливается на своей высоте 893–911; ширина кофейного пятна 818:140 → 822:220 → 826:235 (ease.out); два серых кольца ряби расходятся до ширины 560/460 и гаснут до 838; полукруг ручки + ярлычок чайного пакетика остаются на полу.
- Линии движения при шлепке: 3 короткие линии справа от чашки, после удара за 12 кадров расходятся и гаснут.

## Вторичная анимация окружения
- Люстра: `damped(F, 686, 0.055rad, период 26 кадров, затухание 22 кадра) + damped(F, 830, 0.045, 22, 20)`, световой конус качается вместе с ней.
- Растения: `damped(F, 697, 0.035, 22, 18)` (качание) + `damped(F, 821, 0.05, 9, 26)` (дрожь, короткий период); у монстеры каждый лист дополнительно немного качается сам по себе с разной фазой.
- Облака сдвигаются влево на 15px/s (0.25px/кадр); маленький самолёт 177px/s тянет пунктирный след (на 12.0 с при x≈440, на 13.75 с при x≈750 — совпадает с оригиналом); лучи солнца вращаются с 0.35 rad/s; 17 декоративных символов «кипят» на 4fps (±1.5px, ±0.09rad).
