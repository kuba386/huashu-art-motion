# 15_raytrace · 1993 ранняя CGI с трассировкой лучей

Без 3D-движка: за счёт «соглашений о шейдинге» в 2D Canvas изображение выдаётся за вывод рендерера.

## Пластиковый шейдинг (через него проходит каждая часть)
`plastic(c, path, base, hx, hy, R)`:
1. Заливка основным цветом;
2. Радиальный градиент с центром в точке блика (hx,hy) и радиусом R: 0→белый .55, 0.28→белый .06, 0.62→прозрачный, 1→тёмно-фиолетовый `rgba(10,0,30,.42)` (затемнение краёв = объём);
3. Рефлекс окружения: через `lighter` накладывается кольцевая обводка `rgba(70,150,150,.28)` шириной 0.18R со смещением влево на 0.04R — стена бирюзовая, значит и рефлекс бирюзовый;
4. Один жёсткий белый эллиптический зеркальный блик (0.16R × 0.09R, непрозрачность .85). Именно этот штрих больше всего похож на Фонга 90-х.

Конечности — `cyl()`: градиент поперёк конечности по направлению нормали (тёмный .25 → узкая белая полоса .5 на 22% → тёмный .45), плюс тонкая белая линия блика на участке 20%–75%.
Девушка — Path2D из RIG.girl (длинные волосы), юбка заменена синими пластиковыми цилиндрами-ногами + шаровые шарниры коленей, на плечах тоже шаровые шарниры — то самое ощущение суставов «игрушечной куклы».
Тело кошки в RIG — ломаная, пластиковый шейдинг выдаёт углы: сначала `RIG.smooth(K.bodyPts)`, затем шейдинг. Тигровые полосы рисуются с `filter: blur(2px)` как мягкие полосы, «отпечатанные под пластиком».

## Сцена
- Стена: радиальный градиент `#7dbcb9 → #64a6a6 → #3f8285`, источник света — на месте окна; тень окна с `blur(10px)` смещена вправо вниз.
- За окном: розово-фиолетовое градиентное небо (`#a24cc4 → #df62ae → #f5a08a → #f8c070`), два слоя гор, поверх горного массива розовая каркасная сетка 28×26 (wireframe-ландшафт ранней CG), снежные вершины — зубчатые треугольники.
- **Пол**: попиксельная перспективная шахматная доска, точка схода (960,480), `X=(x-960)/dy, Z=1/dy`, клетка TX=0.27, TZ=0.00029, суперсэмплинг 2×2 для сглаживания, в пределах 140px у стены добавляется 35% тумана. В кэше, холодный старт всей сцены 53 мс.
- **Отражение**: слой объектов (стул / стол / девушка / кошка) рисуется в offscreen-слой, зеркалится `translate(0, 2*906); scale(1,-1)` и с `globalAlpha .34` рисуется в область отсечения пола; реквизит зеркалится каждый по своей линии касания пола (конус 780, фиолетовое кольцо 846, хромированный шар 800) и **сначала рисуется в отдельный слой, а затем целиком полупрозрачно** — иначе 140 шариков фиолетового кольца, наложенные каждый с .34, становятся непрозрачными.
- Стеклянный стол: полупрозрачный зелёный эллипс + толстый край + белая обводка, косой блик скользит со скоростью 260px в секунду.

## Мини-циклы (должны быть заметны за 0.23 с)
- Фиолетовое кольцо: 140 шаров расположены по тору, вращение вокруг вертикальной оси 7 rad/s, наклон 0.35, отрисовка с сортировкой по глубине (сначала тёмно-фиолетовая подложка, чтобы шары сливались в трубку, затем радиальный блик на каждом шаре). За 0.23 с поворот на 1.6 rad — из анфаса в профиль, очень заметно.
- Хромированный шар: каждый кадр попиксельный environment mapping (вектор отражения вниз → шахматная доска, вверх → розово-фиолетовое небо + полоса света из окна), координата u доски сдвигается по `t*4.5` = шар вращается; осветление краёв по Френелю. Диаметр 104px, <2 мс на кадр.
- Блик объектива (`lighter`): свечение солнечного ядра 170px пульсирует с 23 rad/s на ±8%; 12 звёздных лучей вращаются с 1.6 rad/s; горизонтальная полоса света 960px; 5 «призраков» (круги + шестиугольники) расположены по прямой «солнце → центр кадра» и скользят по `sin(t*5)*0.03`.
- Зелёное свечение глаз кошки: радиальный градиент `lighter` радиусом 46px пульсирует с 18 rad/s на ±25%.
- Чашка в руке (choreo.cup), взмахи хвоста, моргание, пар — как обычно.

## Грабли
- Wireframe-переход вычисляет и кэширует контуры по кадру, в котором новая сцена появляется впервые (`once('edges')`), поэтому кадр lt≈0 должен быть полным — не оставляйте пустоту или fade-in на lt=0.
- Производительность: горячий кадр 23 мс, холодный старт 53 мс.
