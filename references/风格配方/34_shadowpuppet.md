# 34_shadowpuppet · Китайский театр теней

> Источник: тест переноса D (выполнен независимым агентом, который только читал skill, 2026-10-04). После интеграции код сцены перенесён в `scripts/engine/scenes/34_shadowpuppet.js`.

Имя файла в эксперименте: `scenes/r3_piying.js`, около 121 мс на кадр (каждая кожаная деталь в отдельном офскрине, много вызовов multiply).

**Пайплайн**: экран театра теней (тёплый радиальный свет масляной лампы за экраном + горячая точка фитиля через screen + текстура ткани 3px, текстура кэшируется) → слой реквизита (оконная решётка, стол, ваза с цветами, стул с прямой спинкой, кэшируется) → бабочка → кошка → девушка, каждая группа в своём офскрин-слое → для каждого слоя сначала печатается смещённая мягкая тень, затем multiply самой фигуры → заклёпки → управляющие трости → деревянная рамка.

**Ключевые параметры**
- Функция кожаной детали `piece(g, path, col, carve)`:
  - Заливка цветом.
  - Внутри clip через destination-out вырезается узор.
  - Внутри clip обводится «кожаный край» того же цвета шириной 2×edge, чтобы резьба не прорезала внешний контур.
  - Обводка 2.6px тёмно-коричневым #3a160a.
- Библиотека резных узоров:
  - «Рыбья икра» dots: s14–22, r3–3.5.
  - Цветочные розетки flowers: 5 эллиптических лепестков, s36–46.
  - Облачный узор clouds: маленькие архимедовы спирали, толщина 3.4, s24–40.
  - Решётка lattice: s26–32.
  - Резные линии lines: толщина 3–7.
- Печать на экран: `stamp(layer)` сначала multiply α0.28, blur 6px, смещение (7,5) — размытая тень детали, неплотно прижатой к экрану; затем multiply самой фигуры. Просвечивание = цвет экрана × цвет кожи, перекрывающиеся детали естественно темнеют.
- Цвета: красный #c0352a, зелёный #2f7d4c, янтарный #d99a2e (светлые волосы = кожа янтарного цвета), жёлтый #e2bd4a, синий #2c5a8a, рыжий #d9782a (кошка).
- Экран: радиальный #fff6d6 → #f2d7a0 → #cf9a58 → #7a4a20; колебание пламени `fl = 0.5·noise(3ts) + 0.3·noise(9ts)`, ts ступенчато с частотой 15fps. Центр света дрейфует на ±26/±18px, радиус горячей точки 260+40·fl.
- «Пустое лицо» амплуа дань (женская роль): после отрисовки волос всё лицо удаляется через destination-out, обводится только контур лица, затем дорисовываются «глаза феникса» (длинная линия, загнутая вверх + нижнее веко + точка зрачка), брови-ивовые листья, точка губ.
- Отображение рыже-белой кошки: рыжее = рыжая кожа; белая грудка, белая мордочка, белые лапы и белые подушечки = **полностью вырезаны, остаётся только кожаный край**; полосы = резные линии. Это правило подходит для всех «силуэтных/прорезных» стилей: белые части просто вырезаются насквозь.
- Движения:
  - Девушка целиком качается вокруг (1260,930) на ±0.012rad; голова поворачивается вокруг заклёпки на шее на ±0.06.
  - Подъём чашки ступенчатый, 10fps.
  - Свободное запястье: dangle = 0.35·sin(11·ls)·(1 − 0.6·cup), чашка болтается вместе с рукой.
  - Голова кошки кивает вокруг точки шеи 0.1·sin(6ts) + 0.05.
  - Хвост — 4 шарнирных сегмента, каждый поворачивается относительно предыдущего на 0.3·sin(7ts − 0.9i) + 0.38, кончик-хлыст запаздывает сегмент за сегментом.
  - Нити бусин шпильки-буяо раскачиваются.
- Трости: тёмно-коричневые линии 5px, blur 1.2px, multiply, идут от шеи, запястья, спины кошки, головы кошки, бабочки к нижнему краю кадра.

**Анимация мотивных движений**: пламя лампы заставляет прыгать световое пятно по всему экрану, бабочка (крылья переворачиваются через scaleX ступенчато с частотой 12fps, с тростью), болтающееся запястье, кивание кошки и хлыст хвоста, шпилька-буяо. Площадь движения 6.8%.

**Подводные камни**
- Ножка стола лежала поверх юбки: после multiply красный×зелёный почти чёрный, получилась чёрная трапеция. В театре теней потемнение при перекрытии — это правильно, но не ставьте перекрытие в визуальный фокус — достаточно сдвинуть ножку стола.
- Передние лапы кошки в первой версии были одним сплошным рыжим прямоугольником и закрывали белую грудку. Только после замены на две почти полностью вырезанные белые лапы стало читаться «рыже-белая».
- Трости, пересекающие главный объект, создают хаос: трости должны идти от детали вниз и наружу, не пересекая других персонажей.
