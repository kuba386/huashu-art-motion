# 05 · Ритм и музыка

Метод разбора и переиспользуемые закономерности: `风格配方/_音轨_艺术史速通.md` (разбор звуковой дорожки Art History Speedrun; раздел 5 «Переиспользуемые закономерности» можно копировать напрямую); шаблон скрипта синтеза (оригинальная примерная партитура): `scripts/audio/synth_艺术史速通.py`.

## Ключевые моменты

1. **Сначала задай сетку BPM, изображение и музыка попадают на неё.** 128 BPM, восьмая нота 0.234s — подходит для спидрана/монтажа. `eighths` в `eras.js` — это сколько восьмых занимает каждый сегмент.
2. **Ускорение — за счёт укорачивания сегментов, а не повышения темпа.** 6 → 4×5 → 3×4 → 2×3 → 1×3 → финал растянут.
3. **Один мотив из трёх нот, в каждом сегменте — характерный для стиля инструмент, транспонирование вслед за аккордом.** Для гармонии достаточно цикла из четырёх аккордов.
4. **Между сегментами — жёсткие атаки, без кроссфейда, без свиста.**
5. **Финальные звуковые эффекты: стоп — зависание — удар — реакция — завершение** (дзинь → свисток-глиссандо падения → разбивание → мяуканье → басовое пиццикато), точки времени совпадают с кадрами событий изображения.
6. **Громкость**: совпадение с интегральной LUFS и true peak референсного ролика; сравнивай относительные разницы по сегментам.
7. То, как мультимодальная модель слышит звук, — только кандидат: инструментам можно верить, а BPM, число нот мотива, время звуковых эффектов нужно перепроверять детекцией атак.

## Синхронизация с изображением

- Начало перехода = точка сетки; удар камеры (слой сцены 1.03 → 1.0, 20 кадров) приходится на ту же точку — слышимый «щелчок» и видимый рывок становятся одним и тем же моментом.
- Кадры действий финальной сцены (3-й хлопок по чашке, падение чашки) совпадают с аудио onset, погрешность не более 3 кадров.
- Если референсного ролика нет: сначала напиши таблицу сегментов (сколько восьмых в каждом), затем одновременно генерируй таймлайн изображения и музыку; чтобы потом изменить ритм, правится только одно место — `eighths`.
