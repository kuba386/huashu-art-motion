# Совместимость и границы проверки

Дата проверки: 2026-10-08. Ниже разделены установка/настройка, онлайн-выполнение на хосте и фактическая генерация медиа; прохождение на одном уровне не подменяет другой.

## Установка и обновление конфигурации

В изолированном рабочем каталоге Git официальным skills CLI фактически выполнялось `skills add <本地发布包> --skill huashu-art-motion --agent <宿主> --yes --copy` (`<本地发布包>` — локальный релизный пакет, `<宿主>` — хост), по две установки подряд для каждой цели. Все три цели — claude-code, codex, kimi-code-cli — прошли успешно, media.json вне каталога установки побайтно не изменился. Здесь проверено сохранение предпочтений при перезаписывающей переустановке; мы не утверждаем, что полностью смоделированы все прошлые версии или реализации update во всех установщиках.

Старая голосовая конфигурация без переписывания объединяется с новыми полями по умолчанию; новая возможность работы с изображениями остаётся невыбранной и неавторизованной. CLI в установленной копии Codex прочитал исходное предпочтение system и revision, не откатившись к общим значениям по умолчанию.

## Онлайн-запуск на хостах

- Codex CLI 0.160.1: реальная сессия загрузила установленный skill и руководства, выполнила ненастроенное состояние, запрет генерации, отсутствие инструментов, импорт готового изображения, сохранение личного предпочтения system; выходное изображение побайтно совпадает с исходным, источники конфигурации соответствуют ожиданиям.
- Claude Code 2.1.287: установка и локальный CLI работают; онлайн-сессия вернула 429 из-за недельной квоты текущей тестовой среды, регрессия с выполнением модели не завершена. На этом основании нельзя ни пометить онлайн-проверку как пройденную, ни заключить, что Skill несовместим.
- Kimi Code CLI 0.38.0: установка и локальный CLI работают; онлайн-сессия вернула 403 из-за прав доступа текущего тестового аккаунта, регрессия с выполнением модели не завершена. В этой версии неинтерактивный `--prompt` нельзя сочетать с `--auto` или `--yolo`; после исправления команды повтора аккаунт по-прежнему получает 403.

Эти сессии использовали изолированные рабочие каталоги и медиаконфигурацию, но переиспользовали существующие логины на этой машине; это не три новых аккаунта. Когда условия аккаунтов Claude/Kimi восстановятся, онлайн-сценарии нужно прогнать дополнительно. Возможности инструментов зависят от фактической сессии; по названию хоста нельзя заключить, что генерация изображений точно есть.

## Фактические медиа и автотесты

Системный голос macOS и клонирование Volcengine реально сгенерировали короткие фразы; текущая сессия Codex фактически вызвала встроенную генерацию изображений, получила PNG 1536×1024 с прозрачными пикселями и прошла приёмку plan → вызов инструмента → квитанция → копирование в проект и проверка SHA. Вызов инструмента изображений выполнял агент, CLI его не подменял. Этот тест доказывает только путь подключения и свойства файла и не заменяет оценку художественного качества.

Автотесты покрывают объединение конфигурации, ужесточение прав, конкурентную запись, старый вывод PCM, незавершённый голосовой поток, выбор характеристик/тарификации изображений, планы между сессиями, отзыв конфигурации, конкурентную замену изображений и проверку публикуемых объектов. CI работает на Linux; реальный системный голос проверен только в macOS, бэкенды системного голоса для Windows/Linux ещё не реализованы.

## Минимальная воспроизводимая проверка

```sh
python scripts/capabilities.py status --config <一个空JSON文件> --explain
python scripts/capabilities.py image-status --config <禁止生图的JSON> --mode generate
python scripts/capabilities.py use-image --file <现有PNG> --out <项目>/配图/新文件.png
python -m unittest discover -s tests -v
```

(`<一个空JSON文件>` — пустой JSON-файл, `<禁止生图的JSON>` — JSON с запретом генерации изображений, `<现有PNG>` — существующий PNG, `<项目>/配图/新文件.png` — проект/иллюстрации/новый файл.)

Фактическая проверка инструмента изображений по images.md делается снимком текущей schema инструментов; если инструмента нет — явно возвращается unavailable, нельзя выдавать вымышленный инструмент за успех. CI без учётных данных или авторизации платные медиасервисы не вызывает.
