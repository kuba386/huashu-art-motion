# Регламент для авторов эпох (рисование чистым кодом)

Каждая эпоха, за которую вы отвечаете = один файл `scenes/<id>.js`, регистрация:

```js
SCENES['<id>'] = { draw(c, lt, t) { /* заполнить 1920x1080 целиком */ } };
```

- `c`: целевой 2D context; `lt`: локальное время сегмента (секунды, отсчёт от начала перехода в эту эпоху, может немного превышать длительность сегмента); `t`: время всего ролика.
- **Не рисуйте табличку с годом** (правый верхний угол 1500–1890 × 40–210 рисует движок), оставьте там фон и не размещайте важных элементов.
- **Не меняйте `lib/`, `engine.js`, `eras.js`, `transitions.js` и чужие файлы scene**. Нужные вспомогательные функции пишите в своём файле.

## Доступные библиотеки (сначала прочитайте исходники)
- `lib/paint.js` → `PAINT`: шум noise/fbm, текстуры texture/grain/craquelure, рукописные линии roughPath/boilSeed,
  стилевые рендереры strokes (мазки по полю потока, поддерживают зональную палитру palette)/dabs/mosaic/halftone/pixelate/facets, цветовые группы `swatch`, общая хореография `choreo`, steam, particles, внеэкранный холст `scratch(key)`.
- `lib/rig.js` → `RIG`: `RIG.girl(opt)` — скелет девушки (сидит боком, лицом влево; возвращает Path2D всех частей + якорные точки `G.A`), `RIG.drawGirl(c,G,pal)` (pal.mode может быть fill/line),
  `RIG.cat(opt)` — скелет рыже-белого кота (сидит лицом вправо), `RIG.drawCat(c,K,pal)`, `RIG.drawCup`, `RIG.smooth(points)` — сглаженная кривая, `RIG.taper` — конические конечности, `RIG.ik2`.
- **Эталонная реализация: `scenes/09_postimp.js` (Ван Гог)** — посмотрите на её структуру: плоская подмалёвка → перерисовка стилевым рендерером (зональная палитра) → плоская заливка персонажа + мелкие мазки → дорисовка линий → подвижные акценты.

## Жёсткие требования
1. **Один и тот же каркас сцены**: стандартная композиция — окно (350,120)-(810,560), кот сидит на полу (390,610)-(690,905), стол (810,620)-(1200,905), человек (1120,200)-(1500,910). В оригинале каждая эпоха выровнена по этим позициям, переходы тоже от них зависят.
2. **Персонажи**: человек — 17-летняя европейская девушка-блондинка в **девичьем наряде этой эпохи** (одежда скромная); кот — **рыже-белый** (макушка/спина/хвост — рыжий тигровый окрас, морда/грудь/живот/лапы — белые).
   Обязательно на основе скелета и хореографии `RIG.girl` / `RIG.cat` (тот же скелет, тот же набор движений), но манера рисования должна смениться на манеру эпохи: можно взять только Path2D и самому заливать/обводить/делать силуэт, можно добавить одежду на якорные точки, можно деформировать точки скелета под эпоху (например, египетский глаз анфас, чернофигурный силуэт).
3. **Всё в картине должно жить**: действия героини — через `PAINT.choreo(lt,t)` (держит чашку cup, взмах хвостом tail, моргание blink, дыхание breathe),
   плюс 2–4 **маленьких цикла, взятых из визуальных мотивов эпохи** — список см. в `../拆解/分镜表.md` (разбор/раскадровка), «движения в кадре» для каждой эпохи (например: животные наскального рисунка бегут, чередуя две позы; скарабей катит солнечный шар; прокручивается лента меандра; дымит Везувий; по сусальному золоту проходит блик; пролетает орнитоптер; падают лепестки сакуры; мерцают световые пятна…).
   Эпоха держится в ролике всего 0,25–1,4 секунды, действие должно быть **заметно** в этом окне.
4. **Стиль делается кодом**: рендерерами/текстурами/линиями превратите картинку в произведение искусства той эпохи, а не в клипарт. Линии могут «кипеть» с частотой 8–12fps (boilSeed) для ощущения ручной работы.
5. **Производительность**: ≤ 150 мс на кадр (1920×1080). Статические части кэшируйте через `PAINT.cached`. Вся случайность — по сиду, один и тот же t обязан давать один и тот же кадр.

## Референсы
- Кадры этой эпохи из референсного ролика: `../生图/ref/<id>.png` (генерация изображений/ref; композиция, мотивы, палитра — всё, кроме счётчика; кадры вы извлекаете из референсного ролика сами, со skill они не распространяются)
- AI-концепты (та же композиция, уже заменены на блондинку + рыже-белого кота): `../生图/plates/<id>.png` — использовать как художественный референс, **вставлять изображения в кадр запрещено**, рисовать только кодом.
- Движения в кадре, точки начала переходов: `../拆解/分镜表.md`
- Референсный ролик 60fps: `../原片/<参考片>.mp4` (оригинал/референсный ролик; готовите сами)

## Самопроверка (минимум 3 итерации на эпоху)
```sh
cd <你的项目目录>   # каталог вашего проекта; внутри есть 代码工程/ (кодовый проект, скопированный из scripts/engine)
uv run --with playwright python 代码工程/render.py --solo <id> --stills 0,0.3,0.6,0.9 --out 渲染/<id>
uv run --with playwright python 代码工程/render.py --solo <id> --from 0 --to 1.2 --out 渲染/<id>/clip.mp4
```
Склейте свои кадры с кадрами оригинала и концептом бок о бок (PIL) и спросите себя: ① Узнаётся ли с первого взгляда, какая это эпоха/художник? ② Похожа ли девушка на 17-летнюю блондинку, а кот — рыже-белый? ③ Видно ли за 1 секунду, что картина движется? ④ Нет ли ляпов (сдвиги, оборванные линии, неправильные перекрытия, пустоты)?
Если хоть один пункт не проходит — исправляйте, пока не будет хорошо.
