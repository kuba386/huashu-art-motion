# huashu-art-motion · Арт-анимация

Пусть ваш coding agent превращает художественные стили в движущиеся картины.

35 художественных стилей · 9 грамматик объясняющих видео · 8 параметризованных клипов · эталонный код готовых роликов под озвучку

```sh
npx skills add alchaincyf/huashu-art-motion
```

## Что умеет

| Вы говорите | Он делает |
|---|---|
| «Воссоздай эту анимацию», «Разбери этот фрагмент» | Сначала запускает скрипт разбора, измеряет переходы, сетку битов, тепловую карту движения каждого сегмента, затем воссоздаёт кодом по механизму |
| «Сделай анимацию как у Ван Гога / Моне / Баухауса» | Сначала проектирует один кадр, потом оживляет его; 35 карточек стилей служат отправной точкой |
| «Сделай художественную анимацию по моей озвучке» | Раскадровка (таблица кадров) → выбор стиля → холст мира плюс камера → вывод видеодорожки |
| «Сделай ролик, где человек проходит сквозь одну знаменитую картину за другой» | Каркас длинного свитка: каждый мир — отдельный файл сегмента, герой всё время идёт вправо, на границе меняется стиль изображения, камера только вперёд, без возврата |
| «Сделай анимационный фрагмент для объясняющего видео» | Выбирает грамматику по озвучке, принимает JSON и выдаёт клип с длительностью, точной до кадра (горизонтальный и вертикальный формат, возможен прозрачный фон) |
| «В кадре должен быть человек» | Кадры человека делает модель генерации изображений, код отвечает за композитинг, смену кадров и фактуру |
| «Подбери музыку, попади в ритм» | Сетка BPM, смена инструментов для мотива, финальная последовательность звуковых эффектов — всё синтезируется чистым кодом |

Перед сдачей есть цифровая приёмка: `qa.py` измеряет стабильность, эффективность, динамику, плавность и признаки проблем с кадрированием текста, а затем агент, не участвовавший в производстве, смотрит только готовый ролик и ищет проблемы.

## Что внутри

| | Количество |
|---|---|
| Карточки художественных стилей (параметры, действия мотивов, фирменные переходы, текущие слабые места) | 35 шт., `references/风格配方/` (карточки стилей) |
| Соответствующий код сцен | 35 шт., `scripts/engine/scenes/` |
| Карточки грамматик анимации для объясняющих видео | 9 шт.; для 8 из них есть демо-ролики, параметризованные клипы и пример spec |
| Эталонный код готовых роликов под озвучку | Смешанный стиль, белая доска, Vox, ведущий; часть материалов нужно предоставить самостоятельно, подробнее в README каталога |
| Демо длинного свитка (каркас + 3 сегмента + библиотека кадров персонажа) | 1 шт., `scripts/engine/demos/long_scroll/` |
| Переходы | Фирменные переходы художественных стилей и переходы для объясняющих видео, включая затемнение, жёсткую склейку и бумажные переходы |
| Библиотеки рисования и анимации (кисти, рендереры, постобработка, скелеты, камера, графики, типографика…) | 17 шт., `scripts/engine/lib/` |
| Методические документы (разбор, механизм, сначала один кадр, рисование чистым кодом, ритм и музыка, персонажи, длинный свиток…) | 12 основных, `references/01`–`12`; плюс [опциональное руководство по голосу](references/capabilities.md) |

```
huashu-art-motion/
├── SKILL.md                 # сначала определить задачу, затем читать документы по таблице
├── references/              # методические документы 01–12, 35 карточек стилей, 9 карточек грамматик, положительный опыт
├── assets/                  # обзорные изображения (для README)
└── scripts/
    ├── engine/              # анимационный проект, копируемый целиком: движок, переходы, библиотеки, сцены, демо-ролики, клипы
    ├── analyze/breakdown.py # превращает референсную анимацию в «карту, по которой можно писать код»
    ├── qa.py                # приёмка одной командой
    ├── audio/               # шаблоны синтеза музыки чистым кодом
    └── font_subset.py ...   # подмножества шрифтов, вырезание зелёного фона
```

Зависимости: [uv](https://docs.astral.sh/uv/), ffmpeg, Playwright Chromium (при первом запуске выполните `uv run --with playwright playwright install chromium`). Попробуйте:

```sh
cd huashu-art-motion
uv run --with playwright python scripts/engine/render.py --solo 09_postimp --stills 0.3 --out 试渲   # один кадр сегмента Ван Гога
uv run --with playwright python scripts/engine/render.py --spec scripts/engine/examples/t3_finance_chart.json --out 财经图表.mp4
```

## История создания

В начале октября 2026 года я увидел в X 15-секундную анимацию Tak ([@cherry_mx_reds](https://x.com/cherry_mx_reds/status/2106095190285144331)): девушка и кошка проходят сквозь 40000 лет истории искусства, на каждую эпоху приходится около секунды, но всё на картинах движется.

Я попросил Claude воссоздать её. Первая версия была «переходами между отдельными картинками» — я её отклонил: в оригинале на эпоху, может, всего секунда, но элементы внутри картины полностью текучие. Поэтому подход сменился: сначала разбор (измерить переходы, подобрать сетку битов, посмотреть, что движется в каждом сегменте), затем слой за слоем нарисовать картину кодом и оживить её.

В процессе я сказал ему: «Мы делаем это не только ради воссоздания, мне нужно, чтобы ты накапливал опыт». Поэтому в этом skill записан не только код, но и то, какие приёмы доказали свою эффективность (`references/07-正面经验.md`), подводные камни и слабые места каждого стиля. Потом я отправил 4 группы агентов, которые читали только skill, делать 20 незнакомых им стилей, и собрал изобретённые ими велосипеды в единую библиотеку; затем добавил 8 грамматик анимации для объясняющих YouTube-видео и подключил их к своему конвейеру видео с озвучкой. В конце на этом же наборе сделал «Хуашу путешествует сквозь знаменитые картины»: 23 стиля изображения, 2 минуты 08 секунд, я иду от пещеры до 2026 года; каркас и 3 сегмента из него тоже включены сюда.

## English

**huashu-art-motion** is an agent skill for making animation with code, where the paintings actually move. It ships 35 art-style recipes (cave painting, Egyptian murals, Van Gogh, Klimt, Bauhaus, Kirby comics, 8-bit, vaporwave, Shinkai and more), each with a working Canvas scene, a style "renderer" and a signature transition; 8 explainer-video grammars (Kurzgesagt, Vox, whiteboard, storytime, kinetic type, 3Blue1Brown, keynote UI, finance charts) with demo films and parameterized clips you drive with a JSON spec, frame-accurate and in landscape, portrait or alpha; a long-scroll skeleton where a character walks left to right through one painting after another (3 sample worlds included); plus a breakdown script that maps a reference animation into cuts, beat grid and motion heatmaps, and a QA script that measures stability, cost per frame, motion and smoothness.

It started as a code-only recreation of Tak's ([@cherry_mx_reds](https://x.com/cherry_mx_reds/status/2106095190285144331)) 15-second *Art History Speedrun*. The scene layouts and the girl-and-cat premise follow his original; every frame here is redrawn in code, and no frames, screenshots or audio from the original are included.

Install: `npx skills add alchaincyf/huashu-art-motion`. Requires uv, ffmpeg and Playwright Chromium. The skill content in this fork is translated into Russian (original: Chinese). The ninth grammar, presenter-led explainers, ships as a reference implementation and requires your own character assets. Full-narration examples are code snapshots, not ready-to-render projects. Code and docs are MIT; the bundled stroke medians retain the Arphic Public License; bundled fonts keep their SIL OFL licenses; the Huashu character artwork, including its appearance in overview images and demo videos, is for demo use only.

## Опциональные медиавозможности

Для базовой анимации кодом не нужны аккаунты для голоса или изображений. Если материалы есть — используйте их; если нужна генерация — вызывается по выбору пользователя и в рамках текущего окружения. Голос: системные голоса macOS и собственный клонированный тембр Volcano Engine; изображения: импорт имеющихся файлов и мост к инструментам текущего агента/MCP.

- [Голос и личная конфигурация](references/capabilities.md): настройка по необходимости, можно пропустить, старая точка входа koubo совместима.
- [Подключение инструментов для изображений](references/images.md): сначала генерируется план, агент вызывает инструменты, затем проверяет результат и сохраняет материалы.
- [Совместимость и объём проверок](references/compatibility.md): установка и переустановка у трёх платформ пройдены; онлайн-регрессия Codex пройдена, онлайн-регрессия Claude Code/Kimi заблокирована условиями тестовых аккаунтов и ожидает повторной проверки.
- [Сопровождение, расширение и публикация](CONTRIBUTING.md): публичные настройки по умолчанию отделены от личной конфигурации, обновление не перезаписывает личный выбор, проверка перед публикацией охватывает реальные Git-объекты, готовящиеся к публикации.

Сначала выполните `python scripts/capabilities.py status --explain`. Новые возможности по умолчанию не выбраны и не авторизованы; из обнаруженного ключа или инструмента нельзя делать вывод о разрешении на расходы. Отдельный исполнитель API изображений — будущее опциональное расширение, поставщик автоматически не переключается.
